# Agent 系统与智能体 · 课程大纲

前面几章，你写的程序基本是"一问一答"或一条固定流水线：你规定好步骤，模型照着走。但真实任务往往没有固定步骤——"帮我规划一次三天的旅行并订好酒店"，模型得自己判断先查什么、再调用哪个工具、结果不对怎么换办法、什么时候算完成。

能这样**自主决定下一步做什么、并通过调用工具一步步把任务做完**的系统，就叫 Agent（智能体）。它是当下 AI 应用最激动人心的方向，也是把大模型从"会聊天"变成"会办事"的关键。这一章我们会从 Agent 的基本循环讲起，一路走到记忆、安全、工作流编排、工具协议、技能系统和多个 Agent 协作。

## 学习之前

- 已学完第 03 章（调用模型、Function Calling、结构化输出）——Agent 的"调用工具"能力就建立在此
- 本章会用到 LangGraph，建议先学完第 4 章（尤其 4.2 LCEL），上手会顺很多
- 本章概念多、英文缩写多，别慌，我们一个一个用大白话拆，核心其实只有一个"思考—行动—观察"的循环

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | Agent 是什么 | 智能体和普通链的区别；"思考—行动—观察"核心循环；一个最简 Agent 的骨架 |
| 第 02 课 | Agent 的记忆 | 短期记忆与长期记忆；怎么让 Agent 跨轮次、跨会话记住该记的事 |
| 第 03 课 | LLM 安全与对齐 | Agent 能动手意味着风险；提示注入、越权操作怎么防；什么是对齐 |
| 第 04 课 | LangGraph：给 Agent 画流程图 | 用图（节点+边）把复杂、可循环、可分支的 Agent 流程可靠地编排出来 |
| 第 05 课 | MCP：模型上下文协议 | 一套标准让 Agent"即插即用"地接入各种工具和数据源，不用每次重写 |
| 第 06 课 | Agent Skills：技能系统 | 怎么把可复用的能力打包成技能，让 Agent 按需加载 |
| 第 07 课 | Tool Use：工具使用系统 | 工具从设计、描述、调度到错误恢复的完整工程细节；工具生态 |
| 第 08 课 | Multi-Agent：多个智能体协作 | 分工、交接、主管—工人模式；并盘点主流 Agent 框架怎么选 |

> 第 04 课开头配【LangGraph 30 秒补课】小框：节点=一个步骤，边=走向，状态=在节点间传递的数据包。三句话建立直觉，再进正文就不慌。

## 怎么学

1. 抓住一个核心循环：面对任务→想下一步→调用工具→看结果→再想，所有复杂 Agent 都是它的扩展
2. 第 04 课 LangGraph 是本章工程重点，亲手画出节点和边，比读十遍文档管用
3. 第 03 课的安全意识请贯穿全章——一个能真正执行操作的 Agent，安全不是可选项
4. 框架更新极快（MCP、各家 Agent SDK 都在演进），重点学协议和思想，别被某个版本绑死
5. 每课保底一个最小实操：6.1 写出最简 Agent 骨架、6.3 做一次提示注入攻防、6.4 亲手画节点图、6.5 跑通最小 MCP server——章末再手写一遍"思考—行动—观察"循环，动手就不落空
