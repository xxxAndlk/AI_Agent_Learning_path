# Python 入门课程大纲

写给完全没接触过编程的人。一共 12 课，慢节奏，建议每天 1～1.5 小时，三到四周学完。每课都有一段完整可运行的代码和几道动手练习——看会不算会，敲进去跑起来才算。

## 学习之前你需要

- 一台普通电脑（Windows 或 Mac 都行，不需要好显卡）
- 每天能坐下来动手的一小时
- 一个接受"会报错是家常便饭"的好心态

## 课次安排

| 课次 | 主题 | 课上做的东西 |
|------|------|--------------|
| 第 01 课 | 认识 Python | 装好环境，写出第一行代码，让程序和你打招呼 |
| 第 02 课 | 变量与数字 | 用变量和算术做一个 BMI / 个人名片小工具 |
| 第 03 课 | 玩转字符串 | 把乱糟糟的文本整理成想要的样子 |
| 第 04 课 | 列表 | 一个可以增删查看的购物清单 |
| 第 05 课 | 字典与集合 | 通讯录和简单词频统计 |
| 第 06 课 | 判断与循环 | 完整的猜数字游戏 |
| 第 07 课 | 函数 | 把前面写过的代码重构成整洁版本 |
| 第 08 课 | 文件与异常 | 一个关掉再打开数据还在的记账本 |
| 第 09 课 | 模块与第三方库 | 搞懂 pip 和虚拟环境，第一次从网上取数据 |
| 第 10 课 | 面向对象入门 | 用类改写购物车 |
| 第 11 课 | 地道的 Python | 推导式、生成器，以及几个最好用的标准库 |
| 第 12 课 | 并发初窥与结业 | 结业项目：一个完整的命令行待办管理器 |

## 怎么学效果最好

1. 讲义里的代码，**亲手敲**，不要复制。敲错的过程就是学习本身。
2. 每课的练习先自己写，实在卡住再看 exercises 目录里的参考答案。
3. 报错别慌，先读最后一行报错信息，再翻看每课最后的"踩坑对照"。
4. 前面的课没消化，别急着往后赶。这门课的内容是一环扣一环的。
