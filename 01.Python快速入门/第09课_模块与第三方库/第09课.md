# 第 09 课　模块与第三方库

前八课，我们用的都是 Python 自带的东西。这节课要跨出去一步：学会借别人的代码来用，并且第一次让程序从网上取回真数据。AI 时代的好工具几乎都装在这条路上——学完这节，你就推开那扇门了。

---

## 一、模块：其实就是个 .py 文件

先说破一个听起来挺玄的词：**模块**。它不是什么新东西，一个 `.py` 文件就是一个模块。

你自己其实早就在造模块了——第一课写的 `hello.py`，它就是一个模块。只是那会儿我们没这么叫它。

为什么要把代码拆成一个个文件？你想想家里收拾东西：袜子进一个抽屉，证件进另一个抽屉，总不能全塞一个抽屉里，翻找的时候连人带抽屉一起端走。代码也一样，管数学的放 `math`，管随机的放 `random`，要用哪样拿哪样。

### 三种拿法

Python 自带了个管数学的模块，叫 `math`，拿它练手。进入对话模式试试：

```python
>>> import math
>>> math.sqrt(16)     # sqrt = square root，平方根
4.0
>>> math.ceil(3.2)    # ceil = ceiling 天花板，向上取整
4
>>> math.pi           # 圆周率，它帮你存好了
3.141592653589793
```

`import math` 的意思是：把 math 这个抽屉整个搬过来，用的时候喊它的名字——`math.sqrt`，先报名字再点东西。

如果只需要用其中一样，可以只拿那样东西出来：

```python
>>> from math import sqrt
>>> sqrt(25)
5.0
```

这样以后直接写 `sqrt` 就行，不用每次都带上 `math.` 前缀。方便是方便，但如果两个模块里都有叫 `sqrt` 的东西，后拿来的会把先拿来的顶掉——所以抽屉多了以后，很多人反而偏爱第一种写法，名字前面挂着产地，不容易混淆。

还有个偷懒技巧，给长长的名字起个短号：

```python
>>> import math as m
>>> m.sqrt(2)
1.4142135623730951
```

`as` 就是"当作"，以后 `m` 就代表 `math`。写长代码的时候，把 `matplotlib` 缩成 `plt` 这类操作，用的全是这招。

### 自己的文件也能互相借

不只有官方的模块能 import。如果你把函数写进了 `mytools.py`，在同一个文件夹里另建一个文件，写 `import mytools`，就能直接用里面的函数。这招第八课重构记账本的时候你已经间接摸到了边——代码攒多了，就该这样分家。

## 二、标准库和第三方库

Python 自带的这一大批模块，合起来叫**标准库**：math、random、json、csv……装好 Python 就有，不用额外下载。它们像手机出厂自带的计算器、手电筒——开机就能用。

但自带的家伙事儿终究有限。想干更专门的事，比如访问网页、画图表、调 AI 接口，就得装**第三方库**——全世界程序员写好、放到网上共享的代码包。它们像应用商店里的 App，得先下载安装，装完才能用。

存放第三方库的那个"商店"叫 PyPI（Python Package Index），里面存着几十万个包。而帮你去商店下载的工具，叫 **pip**——装 Python 的时候它已经一起装好了。

试一下就明白。打开终端，输入：

```bash
pip install requests
```

它会去 PyPI 把 requests 这个库下载装好，你能在屏幕上看到下载进度。requests 是干什么的马上讲，它也是我们这门课装的第一个第三方库。

> 小提示：如果终端说 `pip` 不是内部或外部命令，改用这行：`python -m pip install requests`。效果一样，而且更不容易出岔子。

## 三、虚拟环境：每个项目自备一个包柜

现在要讲这节课最重要的东西了，新手到后面一定会撞上它，先在这里拆掉。

问题是这样：你以后不会只写一个项目。项目 A 用的某个库是 2.0 版，项目 B 要求必须是 3.0 版。如果所有包装在一起，装 B 的时候就会把 A 要的旧版顶掉，A 当场罢工。这叫版本打架——不是包有问题，是它们被塞进了同一个柜子。

打个比方：合租的房子里大家共用一个调料架，你今天换成辣酱，他明天想吃清淡的就抓瞎。解决办法很简单，一人一个调料罐，各放各的。

**虚拟环境**（venv）干的就是这件事：给每个项目单独配一个装包的柜子，互不干扰。

### 动手建一个

先走到你的项目文件夹，然后输入：

```bash
python -m venv .venv
```

（Mac 用 `python3 -m venv .venv`。）

跑完，文件夹里多出一个 `.venv` 文件夹——这个项目的私人柜子就建好了，以后装的包都放里面。

### 激活它

柜子建好还得"走进去"，这个动作叫**激活**：

```bash
.venv\Scripts\activate
```

Mac 用：

```bash
source .venv/bin/activate
```

激活成功的标志：终端提示符前面多了个 `(.venv)`。看到它，说明你现在装什么包，都只装进这个项目的柜子。

现在再装 requests：

```bash
pip install requests
```

想退出这个环境（换别的项目去了），输入 `deactivate`，`(.venv)` 前缀消失，回到公共区域。

### 新手最常踩的坑

**`ModuleNotFoundError: No module named 'requests'`**

明明装了还说找不到。九成是因为：装的时候没激活虚拟环境，包装进了全局；运行时却在另一个环境里。先看提示符有没有 `(.venv)`，再重新装一遍。

**PowerShell 里激活报红字"禁止运行脚本"**

Windows 的 PowerShell 默认拦执行脚本。开一次权限就永久解决：

```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

不想动设置的，换 cmd 窗口来激活也行。

**`.venv` 文件夹要不要备份？**

不用。它是可以随时重建的（一条命令的事），真正要留底的是下一节要写的 requirements.txt。

## 四、requirements.txt：把购物清单写下来

装好一个项目的所有包之后，总得记下来都装了什么，不然换个电脑、或者给别人用，全得靠回忆。pip 自带导出功能：

```bash
pip freeze > requirements.txt
```

打开看看，里面就是一张清单，每个包连版本号都写得清清楚楚：

```
requests==2.32.5
```

下次（或者别人）拿到你的项目，三步复原环境：建虚拟环境、激活、然后：

```bash
pip install -r requirements.txt
```

`-r` 是 read 的意思：按清单逐个装齐，版本都按单子上的来。这就是菜谱后面附的配料表——拿着它，谁都能把这道菜做出来。

## 五、第一次从网上取数据

铺垫了这么久，正戏来了。装好的 requests 就是干这个的：让你的 Python 程序像浏览器一样去访问网址。

最小用法长这样：

```python
import requests

response = requests.get("https://www.python.org")
print(response.status_code)   # 状态码，200 表示成功
print(response.text[:200])    # 网页内容（前 200 个字符）
```

`requests.get(...)` 相当于你敲下回车去访问一个网址；返回的 `response` 是对方的回应，最有用的是两样：`status_code` 是状态码（200 万事大吉，404 是"没有这个页面"），`text` 是拿回来的网页文字。

网络这东西比文件系统还不可靠：网线被猫咬了、网址敲错了、对方服务器睡着了，都会报错。第八课学的 try/except 在这儿正好派上用场——预判它会出事，把兜底的网先张好。

课上完整程序 `web_fetch.py` 就是这么写的，你运行它，输入一个网址，它会告诉你状态码和页面开头长什么样：

```python
url = input("请输入要访问的网址（比如 https://www.python.org ）：")

try:
    response = requests.get(url, timeout=10)
    print("状态码：", response.status_code)
    print(response.text[:200])
except requests.exceptions.RequestException as error:
    print("访问失败了：", error)
```

留意两个细节。`timeout=10` 是给自己留的退路：不写它的话，万一对方服务器卡住不吭声，你的程序会一直傻等下去。接异常时用的 `requests.exceptions.RequestException` 是 requests 各种网络异常的"总管"，断网、超时、连不上，一个都逃不出它，接住它程序就不会崩出一屏红字。

跑一下试试。输入 `https://www.python.org`，看到 `200`，恭喜——你的程序第一次伸手够到了互联网。

## 小结

这节课往工具箱里放进了四样东西：import 三种拿法（整个搬、拿几样、起短号）；标准库自带、第三方用 pip 装；虚拟环境让每个项目的包各归各位，版本不打架；requirements.txt 存清单，走到哪都能复原。

还有一件值得记住的事：requests 是我们第一个从网上借来的库，而后面课程里会用到的 AI 相关工具，安装和使用方式跟它一模一样——建环境、pip install、import。今天走的这条路，就是通往 AI 生态的主干道。
