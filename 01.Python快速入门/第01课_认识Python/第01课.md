# 第 01 课　认识 Python

这是第一课。这节课结束的时候，你的电脑里会有一个能跑 Python 的环境，你会亲手写出一个小程序，让它开口和你说话。

至于"编程是什么""程序员是不是数学都特别好"这些问题，我们边装边聊。

---

## 一、先聊明白：编程到底在干什么

计算机其实是个**特别听话、又特别笨**的伙计。

听话，是因为你让它干什么它就干什么，干一亿遍也不会累；笨，是因为它自己一点主意都没有——你少交代半句，它就傻在那里，或者干出离谱的事来。

编程，就是把你脑子里想做的事，拆成一小步一小步、交代给它的过程。而编程语言，就是你用来交代事情的语言。

Python 是这些语言里对新手最友好的一种。它的代码长得很接近英语句子，比如想让屏幕显示一句话，你只要写：

```python
print("你好")
```

`print` 在英语里就是"打印"的意思，括号里的内容就会显示在屏幕上。一目了然。

还有一个很现实的理由：这两年最火的 AI，背后那些工具几乎都是用 Python 写的。我们这套教程往后走，调用大模型、做知识库、搭智能体，用的都是 Python。把这门语言学到手，后面的路才走得动。

顺便说一句：学编程不需要数学好。你会加减乘除、做事有条理，就够了。

## 二、把 Python 装到电脑里

Python 是免费的，整个安装过程大概五分钟。

### Windows 系统

1. 打开官方网站：<https://www.python.org/downloads/>
2. 页面上会有一个醒目的下载按钮，默认给你的就是适合 Windows 的最新版本，点它下载
3. 找到下载好的安装文件，双击运行
4. **这一步最重要**：安装窗口底部有一个勾选框，写着 "Add python.exe to PATH"，**一定要打勾**，然后再点 "Install Now"

打勾和没打勾的区别：打了勾，待会儿你在任何地方都能直接喊一声"python"把它叫出来；没打勾，它就像被锁进了杂物间，你得自己摸过去找——几乎所有新手第一节课的报错，都是因为这个勾没打上。

安装过程一路等它走完，点 Close 就行。

### 苹果电脑（macOS）

两种装法，选一种：

- **最简单**：同样打开 <https://www.python.org/downloads/>，下载 Mac 版安装包，双击，一路继续
- **如果你听说过 Homebrew**：打开"终端"，输入 `brew install python3`

Mac 系统自带了一个比较旧的 Python，所以装完之后，我们叫它的时候用的名字是 `python3`，而不是 `python`。这个差别下面会再说。

### 确认装好了

要确认，得先打开一个黑底白字的窗口。这个窗口有好几个名字：终端、命令行、命令提示符，说的都是同一个东西——**你打字给电脑下命令的地方**。

- Windows：按键盘左下角 `Win 键 + R`，在弹出的小框里输入 `cmd`，回车
- Mac：按 `Command + 空格`，输入"终端"两个字，回车

会弹出一个窗口，里面有个一闪一闪的光标。别紧张，在里面输入下面这行，然后回车：

```bash
python --version
```

Mac 用户如果上面这行没反应，就输入：

```bash
python3 --version
```

如果屏幕上回了你一句类似 `Python 3.15.0` 的版本号（也可能是 `3.14.x`，取决于你下载时官网的最新版本），恭喜，安装成功了。记住这个窗口长什么样，以后我们会经常和它打交道。

## 三、和电脑打交道的窗口：终端最小速成

刚才那个窗口就是终端。你可能觉得电影里黑客噼里啪啦敲的就是这玩意，其实新手只需要会三招。

先在窗口里找到光标，输入命令，按回车，它就执行。输错了也不会弄坏电脑，放心试。

**第一招：看看自己在哪儿**

电脑里的文件都放在一个个文件夹里，终端刚打开时，你是站在某个文件夹里的。想知道自己站在哪：

- Windows 输入 `cd`，回车
- Mac 输入 `pwd`，回车

它会显示一个类似 `C:\Users\你的名字` 的路径，意思就是你当前所在的位置。

**第二招：走到另一个文件夹**

用 `cd`（change directory，换个文件夹的意思），后面跟上你要去的地方：

```bash
cd Desktop
```

这行的意思是"走到桌面这个文件夹里"。以后你的练习代码放在桌面上，就先 `cd Desktop` 走过去再运行。

**第三招：看看文件夹里有什么**

- Windows 输入 `dir`，回车
- Mac 输入 `ls`，回车

当前文件夹里的东西会列出来。

就这三招，够你撑过前几节课了。剩下的以后用到再说。

> 小提示：命令输到一半按 `Tab 键`，它会帮你自动补全文件夹名字；按键盘上的 ↑ 键，可以把刚才输入过的命令再叫出来。这两个按键很省事，建议现在就试试。

## 四、先玩一把：Python 的"对话模式"

装好的 Python 自带一个很好玩的东西，你可以把它理解成一个随叫随到的计算器兼草稿本。

打开终端，输入 `python`（Mac 输入 `python3`），回车。

你会发现提示符变了，变成几个大于号：

```python
>>>
```

这就进入了 Python 的"对话模式"（也叫交互模式）。你写一句，它立刻回一句。现在试着输入：

```python
1 + 1
```

回车，它会立刻回答 `2`。再来点复杂的：

```python
365 * 24
```

它会告诉你一年有 `8760` 个小时。

让它说句话：

```python
print("我好像有点学会了")
```

注意：**文字必须用引号包起来**，数字不用。引号的作用是告诉 Python：这里面包着的是一段文字，不是命令。

想离开对话模式的时候，输入 `exit()`，回车，就回到了正常的终端。

这个对话模式很适合随手试想法，但写不了正经程序——因为窗口一关，你写的东西就全没了。下面我们来写一个能保存的。

## 五、写第一个真正的程序

一段程序，说到底就是一个写着代码的文本文件，Python 能读懂它、执行它。

写代码需要一个好用的文本编辑器。这里推荐 **VS Code**，免费，装上之后对你写 Python 帮助很大（会自动提示、用颜色区分内容）：

1. 打开 <https://code.visualstudio.com/>，下载安装
2. 安装好后打开，左边栏点四个小方块那个图标，搜索 "Python"，把微软官方出的那个扩展装上

如果你现在不想再装东西，用系统自带的记事本也完全能上完这节课。

### 动手写

在桌面上新建一个文件夹，叫 `python课`（用英文或中文都行）。然后在 VS Code 里打开这个文件夹，新建一个文件，名字叫 `hello.py`。

`.py` 是 Python 文件的标志后缀，**后缀名不能错**。Windows 上要小心一个坑：系统默认会藏起后缀，结果你以为文件叫 `hello.py`，其实它叫 `hello.py.txt`。为了避免这个乌龙，在文件夹上方的"查看"里，把"文件扩展名"勾上，就能看到文件的真实名字了。

在 `hello.py` 里敲入下面这些内容。我建议你**一个字一个字敲**，包括括号和引号：

```python
print("你好，世界！")
print("我正在学 Python，今天是第 1 天。")

name = input("你叫什么名字？")
print("很高兴认识你，" + name + "！")
```

保存文件（`Ctrl + S`，Mac 是 `Command + S`）。

### 逐行看它在说什么

- 第 1、2 行：让屏幕显示两句话。引号里是什么，它就显示什么
- 第 4 行稍微复杂点：`input(...)` 会在屏幕上显示括号里的那句提问，然后**停下来等你打字**。你输入的内容会被起个名字存起来，这个名字叫 `name`
  - 你可以把 `name` 想成一个贴了便签的盒子，你从键盘敲进去的东西就放进了这个盒子。下一课我们会专门讲它
- 第 5 行：把三段文字拼在一起显示。中间那个 `name` 没加引号——因为加了引号它就只会显示 "name" 这四个字母，不加引号，Python 才会去盒子里把你真正输入的名字取出来

### 跑起来

打开终端，先走到桌面、再走进你刚建的文件夹：

```bash
cd Desktop
cd python课
```

然后输入：

```bash
python hello.py
```

Mac 用 `python3 hello.py`。

程序会先跟你打招呼，然后问你名字。输入你的名字，回车——它认识你了。

如果你走到了这一步，不管中间报了几次错，你都已经完成了绝大多数人一辈子没做过的事：**让计算机按照你写的指令干活**。

## 六、新手最常踩的坑

报错不可怕，可怕的是不知道错在哪儿。这张表覆盖了第一节课 90% 的问题，建议遇到报错先回来查。

**终端说 `'python' 不是内部或外部命令`**

Python 没被加进 PATH。多半是安装时那个勾没打上。最省事的办法是重新运行安装程序（选 Modify），或干脆卸载重装，记得打勾。

**`.py` 文件双击后黑窗口一闪就没了**

不要双击运行。正确姿势是在终端里输入 `python 文件名.py`。双击时程序确实跑了，但跑完立刻关窗，你什么都来不及看见。

**`can't open file ... No such file or directory`**

Python 找不到你要运行的文件，意思是你的终端当前站的文件夹不对。用前面学的 `pwd`（或 `cd`）看看自己在哪儿，再用 `cd` 走到存放文件的文件夹去。

**文件图标是记事本，名字其实是 `hello.py.txt`**

Windows 藏了后缀名。在文件夹"查看"菜单里勾上"文件扩展名"，然后把名字真正改成 `hello.py`。

**输入 `python` 后进去了不知道怎么出来**

输入 `exit()` 回车。

## 小结

这节课没有什么要背的，你只要真的动手做到了三件事就合格：装好了 Python（`python --version` 能看到版本号）、在终端里跑通过命令、写出了 `hello.py` 并让它和你打招呼。

如果程序没跑起来也别灰心，把报错最后一行读懂，对照上面的坑表，十有八九能解决。实在绕不过去，就把你在终端里看到的报错原样记下来——这本来就是学编程的一部分。

## 课后练习

先自己动手，卡住了再打开 `exercises` 文件夹看参考答案。

**练习 1（必做）：自我介绍**

新建一个文件，运行后在屏幕上整齐地显示三行：你的名字、你所在的城市、你的一个爱好。想想每句话需要用几个 `print`。

**练习 2（必做）：打印一个小图案**

用多个 `print`，在屏幕上用星号 `*` 拼出一个简单图案，比如一个三角形、一棵小圣诞树，或者一个方块房子。引号里可以放空格，空格也会被原样显示。

**练习 3（必做）：拿 Python 当计算器**

进入对话模式（输入 `python` 回车），用它算一道你生活里的题。比如：一件 399 元的衣服打 7.5 折是多少钱？你每天睡 8 小时，一年有多少小时是醒着的？用 Python 算出来。

把课上的 `hello.py` 改一改：除了问名字，再问一个你喜欢的食物，然后让它回答"原来你喜欢吃 XX 呀，我也喜欢！"。提示：需要再用一次 `input`，再起一个名字存起来。
