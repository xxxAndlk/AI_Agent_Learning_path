# 第 01 课　认识 Python

这是第一课。课程结束时，你的电脑里会有一个能运行 Python 的环境，你会亲手写出一个小程序，让它在屏幕上回应你。

安装之前，先说清楚两件事：编程是什么，以及学编程需不需要数学好。

---

## 一、先聊明白：编程到底在干什么

计算机有两个特点：执行快、不知疲倦，但没有自主判断。你让它做什么它就做什么，做一亿次也不会累；可只要少交代半句，它就停在那里，或者做出和预期不符的结果。

编程，就是把你想要做的事拆解成一步步的操作，写成计算机能执行的指令。编程语言，就是书写这些指令的语言。

Python 是对新手最友好的语言之一，代码写法接近英语。想让屏幕显示一句话，只需要写：

```python
print("你好")
```

`print` 的意思是"打印"，括号里的内容会显示在屏幕上。

注意这行里的括号 `( )` 和引号 `" "` 都必须是**英文半角符号**：敲代码前先把输入法切到英文。要是敲成中文的 `（ ）`、`“ ”` 或中文逗号，计算机会报 `SyntaxError`（语法错误）。它和漏勾 PATH 一样，是新手第一节课最常踩的坑，后面所有代码都遵守这条。

还有一个现实原因：当前的 AI 开发工具大多用 Python 编写。本课程后面的调用大模型、构建知识库、开发智能体，用的都是 Python。

另外，学编程不需要数学很好。会加减乘除、做事有条理，就够用了。

---

## 二、把 Python 装到电脑里

Python 是免费的，整个安装过程大概五分钟。

### Windows 系统

1. 打开官方网站：<https://www.python.org/downloads/>
2. 页面上有一个醒目的下载按钮，默认就是适合 Windows 的最新版本，点它下载
3. 找到下载好的安装文件，双击运行
4. 关键的一步：安装窗口底部有一个勾选框，写着 "Add python.exe to PATH"，勾上它，然后再点 "Install Now"

打勾和没打勾的区别：打了勾，之后在任何文件夹都能直接运行 python 命令；没打勾，终端会找不到 python。几乎所有新手第一节课的报错都源于这个勾没打上。

等安装结束，点 Close。

### 苹果电脑（macOS）

两种装法，选一种：

- 常规方式：同样打开 <https://www.python.org/downloads/>，下载 Mac 版安装包，双击，一路继续
- 如果你用过 Homebrew：打开"终端"，输入 `brew install python3`

Mac 系统自带一个较旧的 Python，所以新装的这一个要用 `python3` 来调用，而不是 `python`。这个差别后面会用到。

### 确认装好了

确认之前，先打开一个黑底白字的窗口。它有几个名字：终端、命令行、命令提示符，指的都是同一个东西：你打字给电脑下命令的地方。

- Windows：按键盘左下角 `Win 键 + R`，在弹出的小框里输入 `cmd`，回车
- Mac：按 `Command + 空格`，输入"终端"两个字，回车

弹出的窗口里有一个光标。输入下面这行，回车：

```bash
python --version
```

Mac 用户如果上面这行没反应，就输入：

```bash
python3 --version
```

屏幕上出现类似 `Python 3.15.0` 的版本号（也可能是 `3.14.x`，取决于你下载时官网的最新版本），说明安装成功。记住这个窗口，后面的课会经常用到它。

---

## 三、和电脑打交道的窗口：终端最小速成

刚才那个窗口就是终端。新手只需要会三个操作。

输入命令，按回车，命令就执行。输错了也不会损坏电脑，可以放心试。

第一个操作：查看当前位置

电脑里的文件都存放在文件夹中，终端刚打开时处于某个文件夹里。查看当前位置：

- Windows 输入 `cd`，回车
- Mac 输入 `pwd`，回车

它会显示一个类似 `C:\Users\你的名字` 的路径，就是当前所在位置。

第二个操作：切换文件夹

用 `cd`（change directory，改变目录），后面跟上目标文件夹：

```bash
cd Desktop
```

这行的意思是进入桌面文件夹。以后练习代码放在桌面时，先执行 `cd Desktop` 再运行。

第三个操作：查看文件夹内容

- Windows 输入 `dir`，回车
- Mac 输入 `ls`，回车

当前文件夹里的内容会列出来。

这三个操作够前几节课使用，其余命令以后用到再讲。

> 小提示：命令输到一半按 `Tab 键`，它会帮你自动补全文件夹名字；按键盘上的 ↑ 键，可以把刚才输入过的命令再调出来。这两个按键很省事，建议现在就试试。

## 四、先玩一把：Python 的"对话模式"

装好的 Python 自带一个交互环境，可以把它理解成随开随用的计算器兼草稿本。

打开终端，输入 `python`（Mac 输入 `python3`），回车。

提示符会变成几个大于号：

```python
>>>
```

这就进入了 Python 的对话模式（也叫交互模式）。写一句，它立刻回一句。试着输入：

```python
1 + 1
```

回车后立刻得到 `2`。再试一个：

```python
365 * 24
```

结果是 `8760`，一年的小时数。

再让屏幕显示一句话：

```python
print("我好像有点学会了")
```

注意：文字必须用引号包起来，数字不用。引号的作用是告诉 Python，引号里是一段文字，不是命令。

想离开对话模式，输入 `exit()` 回车，回到正常终端。

对话模式适合随手试验，但写不了正经程序：窗口一关，输入的内容就没了。接下来写一个能保存的。

## 五、写第一个真正的程序

程序就是一个写着代码的文本文件，Python 能读取并执行它。

写代码需要一个文本编辑器，推荐 VS Code：免费，装上后写 Python 有自动提示和颜色区分：

1. 打开 <https://code.visualstudio.com/>，下载安装
2. 安装好后打开，左边栏点四个小方块那个图标，搜索 "Python"，把微软官方出的那个扩展装上

如果暂时不想装软件，用系统自带的记事本也能上完这节课。

### 动手写

在桌面上新建一个文件夹，叫 `python课`（用英文或中文都行）。然后在 VS Code 里打开这个文件夹，新建一个文件，名字叫 `hello.py`。

`.py` 是 Python 文件的后缀，后缀名不能错。Windows 上有一个常见问题：系统默认隐藏后缀，你以为文件叫 `hello.py`，实际它叫 `hello.py.txt`。解决办法：在文件夹上方的"查看"里勾上"文件扩展名"，就能看到文件的真实名字。

在 `hello.py` 里敲入下面的内容。建议逐字敲，包括括号和引号：

```python
print("你好，世界！")
print("我正在学 Python，今天是第 1 天。")

name = input("你叫什么名字？")
print("很高兴认识你，" + name + "！")
```

保存文件（`Ctrl + S`，Mac 是 `Command + S`）。

### 逐行看它在说什么

- 第 1、2 行：让屏幕显示两句话。引号里是什么，就显示什么。
- 第 4 行：`input(...)` 在屏幕上显示括号里的提问，然后停下来等你打字。你输入的内容被存进一个叫 `name` 的变量里。
  - `name` 可以理解成贴了便签的盒子，从键盘敲进去的东西就放进这个盒子。下一课专门讲它。
- 第 5 行：把三段文字拼在一起显示。中间的 `name` 没加引号，因为加了引号只会显示 "name" 这四个字母；不加引号，Python 才会从盒子里取出你实际输入的名字。

### 跑起来

打开终端，先走到桌面、再走进你刚建的文件夹：

```bash
cd Desktop
cd python课
```

然后输入：

```bash
python hello.py
```

Mac 用 `python3 hello.py`。

程序先打招呼，然后问名字。输入你的名字回车，它会打出欢迎语。

走到这一步，计算机已经按照你写的指令干活了。

## 六、新手最常踩的坑

报错不可怕，不知道错在哪才麻烦。下面几种情况覆盖了第一节课 90% 的问题，遇到报错先回来查。

- `'python' 不是内部或外部命令`：Python 没有加入 PATH，多半是安装时那个勾没打上。最省事的办法是重新运行安装程序（选 Modify），或卸载重装，记得打勾。
- `.py` 文件双击后黑窗口一闪就没了：不要双击运行。在终端里输入 `python 文件名.py`。双击时程序跑了，但跑完立刻关窗，来不及看输出。
- `can't open file ... No such file or directory`：Python 找不到要运行的文件，终端当前所在的文件夹不对。用 `pwd`（或 Windows 的 `cd`）查看当前位置，再用 `cd` 走到存放文件的文件夹。
- 文件图标是记事本，名字其实是 `hello.py.txt`：Windows 隐藏了后缀。在文件夹"查看"菜单勾上"文件扩展名"，再把名字改成 `hello.py`。
- 输入 `python` 后不知道怎么退出：输入 `exit()` 回车。

## 想一想

下面几个问题没有标准答案，说出理由就算过关，最好挑一两个动手验证：

1. 编程就是把一件事拆成一步步的指令交给计算机执行。想想你教家里长辈用手机的一个场景：哪句话因为拆得不够细，把对方卡住了？

2. 对话模式里输入 `print("你好")`，和只输入 `"你好"`，屏幕上显示的东西有什么不一样？先猜，再各试一次对答案。

3. 装 Python 时 "Add python.exe to PATH" 的勾没打，后面哪一步会出什么错？翻看前面的故障对照，验证猜测。

4. `hello.py` 和 `hello.py.txt`，Python 只认哪一个？`hello.py.txt` 是怎么产生的？

## 小结

这节课没有要背的内容，动手做到三件事就合格：装好 Python（`python --version` 能看到版本号）、在终端里跑通命令、写出 `hello.py` 并运行成功。

程序没跑起来时，把报错最后一行读懂，对照前面的故障对照，多数问题能自己解决。绕不过去就把终端里的报错原样记下来，这是学编程的常规部分。

## 课后练习

先自己动手，卡住了再打开 `exercises` 文件夹看参考答案。

练习 1（必做）：自我介绍

新建一个文件，运行后在屏幕上整齐地显示三行：你的名字、你所在的城市、你的一个爱好。想想每句话需要用几个 `print`。

练习 2（必做）：打印一个小图案

用多个 `print`，在屏幕上用星号 `*` 拼出一个简单图案，比如一个三角形、一棵小圣诞树，或者一个方块房子。引号里可以放空格，空格也会被原样显示。

练习 3（必做）：拿 Python 当计算器

进入对话模式（输入 `python` 回车），用它算一道你生活里的题。比如：一件 399 元的衣服打 7.5 折是多少钱？你每天睡 8 小时，一年有多少小时是醒着的？用 Python 算出来。

练习 4（选做）：让程序多问一句

把课上的 `hello.py` 改一改：除了问名字，再问一个你喜欢的食物，然后让它回答"原来你喜欢吃 XX 呀，我也喜欢！"。提示：需要再用一次 `input`，再起一个名字存起来。
