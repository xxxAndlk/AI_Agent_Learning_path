## 一、比较运算：程序怎么提问题

先认识六种比较运算符，一半你可能在数学课上见过：

| 运算符 | 意思 | 例子 | 结果 |
|--------|------|------|------|
| == | 等于 | 5 == 5 | True |
| != | 不等于 | 3 != 4 | True |
| > | 大于 | 7 > 10 | False |
| < | 小于 | 2 < 9 | True |
| >= | 大于或等于 | 6 >= 6 | True |
| <= | 小于或等于 | 4 <= 3 | False |

比较的结果只有两种：`True`（真，成立）和 `False`（假，不成立）。这种只有真假两种取值的值，叫**布尔值**。你可以把它想成电灯开关：只有开和关两个状态，不存在"开了一半"。

进对话模式亲手试试，注意 `==` 两边可以是数字，也可以是文字：

```python
>>> 10 > 3
True
>>> 3 + 4 == 7
True
>>> "python" == "Python"
False
```

最后一条值得多看一眼：文字比较区分大小写，`python` 和 `Python` 在它眼里是两个不同的词。

### 一个 = 和两个 == ，差远了

新手第一大坑来了。这两个符号长得像，干的完全是两件事：

- `=` 是**赋值**：把右边的值装进左边的盒子里。`age = 12` 的意思是"把 12 放进叫 age 的盒子"
- `==` 是**比较**：问一句"两边相等吗？"，回答 True 或 False

类比一下：`=` 是把牛奶倒进杯子——倒完就完事，杯子里的东西变了；`==` 是端起两杯牛奶比一比——谁也没动，只答一句"一样"或"不一样"。

写混了会怎样？把 `if x == 5` 写成 `if x = 5`，Python 会直接报 `SyntaxError`（语法错误），程序根本跑不起来。好消息是它起码会喊疼，你马上就能发现。

## 二、而且、或者、不是：and、or、not

有时一个条件不够用。"能玩过山车，要求买了票**而且**身高达标"，缺一不可；"可以用现金**或者**手机付款"，二选一就行。

- `and`：两边都成立，整体才成立。像游乐园的双道检票口，票和身高卡两张都查过才放行
- `or`：两边有一个成立，整体就成立
- `not`：唱反调，True 变 False，False 变 True

```python
>>> age = 12
>>> height = 130
>>> age >= 10 and height >= 120
True
>>> age < 10 or height >= 120
True
>>> not age >= 10
False
```

写复杂条件的小建议：拿不准优先级时大胆加括号，比如 `(a and b) or c`——括号不花钱，思路却清楚得多。

## 三、if、elif、else：看情况办事

有了比较和布尔值，就能让程序"看情况办事"了。最基本的样子：

```python
weather = "雨"

if weather == "雨":
    print("带伞再出门。")

print("这句不归 if 管，无论如何都会执行。")
```

`if` 这行用比较结果当开关：成立，就执行它**缩进的**那几行；不成立，跳过去。最后那句 `print` 的缩进和 `if` 平齐，说明它不在管辖范围内，天天都执行。

加上"否则"：

```python
score = 58

if score >= 60:
    print("及格，放学！")
else:
    print("留堂重考。")
```

情况不止两种时，用 `elif`（是 else if 的缩写）接着排：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

程序从上往下挨个检查，**命中一个就执行，然后整串直接结束**，后面的分支连看都不看。85 分命中的是第二个条件，所以打印"及格"。

### 缩进是 Python 的命根子

别的语言大多用大括号 `{ }` 圈出"哪些话归 if 管"，Python 不用括号，**靠缩进（行首的空格）**：缩进相同的行是一伙的，往里缩一层的行归上一层管。

你可以把它想成写作文的分段——每段开头空两格，读者一眼就知道哪些话属于这段。Python 读代码也是这个感觉。

三条纪律现在记牢，能省掉未来九成的报错：

1. 统一用 **4 个空格**缩进。VS Code 里写 Python 时按 Tab 键，默认插入的就是 4 个空格，不用担心
2. **Tab 和空格别混用**。肉眼看不出来，Python 分得清，混着用必报错。从网页复制代码后报缩进错的，多半是带进了 Tab，删掉重敲最省事
3. 同一层的代码缩进必须一模一样，忽多一个忽少一个都会 `IndentationError`

另外别忘了条件行末尾的冒号 `:`——它的意思是"接下来缩进的都归我管"。忘冒号也是新手常客。

## 四、while：没干完就接着干

接下来是循环。第一个登场的是 `while`（当……的时候）：条件成立，就不停地重复。

```python
count = 1

while count <= 5:
    print(f"这是第 {count} 遍")
    count += 1

print("喊完了，收工。")
```

读法：当 count 不超过 5 时，反复执行缩进里的两行。打印一遍，count 加 1，回头再查条件……直到 count 变成 6，条件不成立，循环结束，程序继续往下走。

一个能正常收场的 while，肚子里必有三个要素，缺一个就可能出事：

- 开跑前给条件备好初值（`count = 1`）
- 条件本身（`count <= 5`）
- 循环体内让条件有朝一日不成立（`count += 1`）

第三条最容易漏，漏了条件就永远成立，程序永远打印下去——这就是**死循环**。遇到屏幕疯狂刷屏停不下来，别关终端，按 `Ctrl + C`，相当于给程序踩急刹车，它会立刻停下。这不是故障，是你亲手按停的。

while 的日常感其实很强：妈妈检查作业——"写完了吗？没写完继续写；写完了，才准看电视"。检查、接着干、再检查，就是 while 的全部人生。

## 五、break 和 continue：循环里的两个按钮

**break** 是"提前退场"。循环还没到自然结束的条件，遇到 break 立刻整圈跳出：

```python
count = 1

while True:            # 条件永远成立，本来是个死循环
    print(count)
    if count == 3:
        break          # 数到 3 就退场
    count += 1

print("跳出循环了。")
```

`while True` 加 `break` 是很常见的组合：表面条件是"一直转"，真正的退出时机写在循环体里面。待会儿的猜数字游戏就是这么写的。

**continue** 是"跳过这一轮"。它不跳出循环，只是本轮剩下的部分不干了，直接回头开始下一轮：

```python
count = 0

while count < 10:
    count += 1
    if count == 7:
        continue       # 7 不打印
    print(count)
```

屏幕会打出 1 到 10，唯独没有 7。记住分工：break 是"不玩了"，continue 是"这个不算，下一个"。

## 六、for 和 range：数着数干活

`while` 什么循环都能干，但"把某件事重复固定的次数"这种活，用它写总有点绕。Python 为此准备了 `for`，配上 `range()` 生成的一串数字，用起来最顺：

```python
for i in range(5):
    print(f"第 {i} 个：你好")
```

屏幕打印 5 行，i 依次是 0、1、2、3、4。for 干的活像发牌员：把一串数字挨个发到 i 手里，每发一张，就干一轮缩进里的活；发完了，循环结束。

`range()` 有三种用法，一一试过你就懂了：

```python
range(5)         # 0, 1, 2, 3, 4 —— 只给一个数，从 0 数到它前一个
range(1, 10)     # 1, 2, ..., 9 —— 给两个数，从第一个到第二个的前一个
range(1, 10, 2)  # 1, 3, 5, 7, 9 —— 第三个数是步子，每次跨 2
```

看出规律了吗？**含头不含尾**：`range(1, 10)` 有 1 没有 10。你可以想成去银行取号：说好发到 10 号之前，那 10 号这张牌永远轮不到你。记住这条，能省下很多"怎么少打了一行"的困惑。

那 for 和 while 怎么选？一条经验：**提前知道重复几次，用 for；不知道几次、要看情况，用 while**。猜数字你不知道几次能猜中，所以它天然属于 while。

## 七、循环套循环：点到为止

循环里面还可以再放一个循环，这叫**嵌套**。外层走一步，内层走完一整圈——就像钟表：分针（内层）吱吱扭扭转一整圈，时针（外层）才不动声色挪一格。

```python
for i in range(1, 4):        # 时针：走 3 格
    for j in range(1, 4):    # 分针：外层每走 1 格，它转 3 圈
        print(i, j)
```

一共打印 9 行：(1,1)、(1,2)、(1,3)、(2,1)……你可以对着屏幕数一数，验证"3 乘 3 等于 9"。这个结构正是练习 3 九九乘法表的骨架。

顺带教一个马上用得上的小技巧：`print()` 默认打完就换行，想同一行接着打，加个参数 `print("xx", end="  ")`——end 的意思是"打完以后用什么收尾"，我们改成两个空格，它就不换行了。

## 八、大制作：猜数字游戏

材料齐了。按老规矩，我们分三步把这个游戏"养大"，每步都不长，重点是看清程序是怎么一点点长出完整逻辑的。

### 第一步：只猜一次

先不管循环，只做一次判断。你猜一个数，它告诉你大了还是小了：

```python
import random

answer = random.randint(1, 100)   # 从 1 到 100 里随机抽一个整数
guess = int(input("你猜是几？"))

if guess > answer:
    print("大了。")
elif guess < answer:
    print("小了。")
else:
    print("猜对了！")
```

两处新面孔：

- `import random`：把 Python 自带的 random 模块请进来，它专门管"随机"。`randint(1, 100)` 从 1 到 100 里随机抽一个整数——注意它**两头都包含**，1 和 100 都可能抽到，和 range 的脾气正好相反，别搞混
- `int(input(...))`：input 收进来的一律是文字（第二课讲过），要拿它比大小，得先用 int 转成整数

跑一跑：每次答案都不一样，你大概率一次猜不中。这就是问题——猜不中，程序直接就结束了。真人玩游戏哪能只猜一次？该循环上场了。

### 第二步：反复猜，猜中为止

把"猜一次"塞进 `while True`，猜中就 break：

```python
import random

answer = random.randint(1, 100)

while True:
    guess = int(input("你猜是几？"))

    if guess > answer:
        print("大了，往小猜。")
    elif guess < answer:
        print("小了，往大猜。")
    else:
        print("猜对了！")
        break
```

注意 break 写在 else 分支里：只有"猜对了"才退场，猜大猜小都回去继续。到这里游戏已经能玩了——把它敲进编辑器，认真玩一局。

### 第三步：统计次数（完全体）

最后加个"战绩"：你到底猜了几次？老套路——备一个计数变量从 0 开始，每猜一次加 1：

```python
import random

answer = random.randint(1, 100)  # randint 两头都包含，和 range 不一样
count = 0                        # 计数变量：记你猜了几次

print("我藏好了一个 1 到 100 之间的数，看看你几次能猜中！")

while True:
    guess = int(input("你猜是几？"))
    count += 1

    if guess > answer:
        print("大了，往小猜。")
    elif guess < answer:
        print("小了，往大猜。")
    else:
        print(f"猜对了！就是 {answer}，你一共猜了 {count} 次。")
        break
```

这就是本课最终成品的完整代码，和课次目录里的 `guess_number.py` 一模一样。会玩的玩家大约 7 次就能猜中任意答案：先猜 50 把范围砍一半，再猜 25 或 75……每次都从正中间下手。这个思路数学上叫二分法，你玩着玩着自己就会悟出来。

说明一句：这个版本输入字母会直接报错退出，因为 int() 转不动文字。我们故意先不处理——错误处理是第 8 课的主角，学完回来把它补结实，你正好能体会"程序变健壮"是什么意思。

## 九、新手踩坑对照

**把 `==` 写成 `=`**：`if x = 5:` 直接 `SyntaxError`。装东西一个等号，提问两个等号。

**忘了冒号**：条件行末尾少 `:`，报错有时指向下一行，先查冒号。

**IndentationError**：缩进忽多忽少，或混用了 Tab 和空格。统一 4 空格；复制的代码报这个错，删掉缩进重敲。

**死循环**：条件永远成立、循环体里又忘了更新。按 `Ctrl + C` 急停，回去检查三要素。

**`range(1, 10)` 以为会到 10**：含头不含尾，只到 9。想要 10，写 `range(1, 11)`。

**拿 input 的结果直接比大小**：文字和数字比较（比如 `"9" > 10`）会报 `TypeError`。input 进来的是文字，先 `int()` 再比。

## 小结

这节课的东西看着多，其实就三层：

- 比较和布尔值负责"提问"，and/or/not 把问题串起来，if/elif/else 按答案办事
- while 是"没干完接着干"，for 配 range 是"数着数干"，break 和 continue 是循环里的两个按钮
- 缩进决定"谁归谁管"，这是 Python 立身的规矩，也是新手报错的第一大户

猜数字游戏是你至今写过的第一个有完整逻辑的程序，值得多玩几遍、多改几遍——比如把 1 到 100 改成 1 到 1000，看看平均次数怎么变。

下节课我们学**函数**：把这段越写越长的代码拆开、装盒、贴上标签，让它清爽起来。
