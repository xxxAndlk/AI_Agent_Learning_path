# 第 02 课　变量与数字

上节课，我们用一个叫 `name` 的"盒子"装下了别人输入的名字。这节课我们把盒子这件事讲透，再让 Python 帮你算几笔账。这节课结束时，你会做出第一个真正有点用的小工具：输入身高体重，它告诉你自己的 BMI。

---

## 一、变量：给值贴个标签

先看上节课出现过的那行代码：

```python
name = "小明"
```

这里的 `name` 就是一个**变量**。你可以把它想成一个贴了标签的收纳盒：`name` 是盒子上贴的标签，`"小明"` 是放进去的东西。

`=` 这个符号在这里不是数学里"相等"的意思。它是一个动作：**把右边的东西，放进左边的盒子里**。所以下面这行你应该读成"把 10 放进 age"，而不是"age 等于 10"：

```python
age = 10
```

盒子里的东西随时可以换。换的时候，旧的就没了：

```python
age = 10
age = 11      # 现在 age 里是 11，刚才那个 10 已经被覆盖了
age = age + 1 # 右边先算出 12，再放回 age。现在 age 是 12
```

最后一种写法刚看会有点晕，其实很常用：Python 先把等号右边的 `age + 1` 算出来（用盒子里的旧值），再把结果放回 `age`。"先取出来加一，再放回去"，就这么回事。

还有一个好消息和一个提醒。好消息：Python 的变量不用提前登记"这个盒子只能装数字"——同一个盒子今天装数字、明天装文字都行。提醒：能这么干不代表该这么干，一个变量从头到尾装一类东西，代码才不容易把自己绕晕。

## 二、给变量起名字的规矩

变量名不是随便起的，Python 有几条硬规矩：

- 只能用字母、数字和下划线 `_`，而且**不能拿数字开头**。`name2` 可以，`2name` 不行
- 大写和小写是两个不同的名字：`age` 和 `Age` 是两个变量
- 不能用 Python 自己留用的词（叫"关键字"），比如 `if`、`for`、`class`——这些词它另有安排

下面这条不是硬规矩，但比硬规矩更重要：**名字要让人一眼看懂**。Python 圈子的习惯是多个单词全小写、中间用下划线隔开，比如 `user_name`（用户名）、`total_price`（总价）。这叫蛇形命名，单词像蛇一样趴在地上。对比一下：

```python
a = 100        # 能跑，但三天后你自己都不记得 a 是什么
total_price = 100   # 一眼看懂：总价
```

代码是写给人看的，顺便让机器执行。给变量起个好名字，是新手期就能养成的、回报最高的习惯。

## 三、两种数：整数和小数

Python 处理数字时，最常见的是两种：

- **整数**（int）：不带小数点，比如 `10`、`-3`、`0`
- **小数**（float）：带小数点，比如 `3.14`、`1.75`。就算值是整数，只要带了小数点，比如 `5.0`，它也算小数

想看看一个值到底是什么类型，可以用 `type()` 问一问（在对话模式里玩最方便）：

```python
>>> type(10)
<class 'int'>
>>> type(5.0)
<class 'float'>
>>> type("10")
<class 'str'>
```

注意第三行：`"10"` 带了引号，它是文字，不是数字。这个区别是本节课的重头戏，一会儿专门讲。

## 四、让 Python 算账

加减乘除你都会，Python 里写法和数学几乎一样：

```python
>>> 7 + 2
9
>>> 7 - 2
5
>>> 7 * 2
14
>>> 7 / 2
3.5
```

前三个没什么可说的。但 `/` 有一个新手必知的行为：**它算出来的永远是带小数点的**，哪怕整除也一样：

```python
>>> 10 / 2
5.0        # 注意是 5.0 不是 5
```

Python 的想法是：只要做了除法，结果就可能是小数，干脆统一都给你小数，免得丢信息。记住它，后面看到 `5.0` 就不会慌了。

### 三个新符号

接下来是三个数学课不怎么用、编程里天天见的符号。

**`//` 整除**：除完只留整数部分，小数直接砍掉。

```python
>>> 7 // 2
3
>>> 7.0 // 2
3.0        # 参与运算的有小数，结果就带小数点，但值还是砍过小数的
```

**`%` 取余**：整除除不尽时，剩下的那点。7 除以 2 商 3 余 1，所以：

```python
>>> 7 % 2
1
```

`//` 和 `%` 是一对好搭档。举个分披萨的例子：10 块披萨分给 3 个人，每人分几块、剩几块？`10 // 3` 得 3——每人 3 块；`10 % 3` 得 1——剩下 1 块。判断一个数是单数还是双数，也靠它：`n % 2` 得 0 就是双数，得 1 就是单数。这个用法第 6 课会派上大用场。

**`**` 乘方**：几次方就写几个星号。`2 ** 10` 就是 2 的 10 次方：

```python
>>> 2 ** 10
1024
```

边长 1.75 米的正方形面积？`1.75 ** 2` 一下就出来了。算 BMI 时我们就会用到它。

## 五、谁先算谁后算

和数学一样，Python 算混合运算时讲先来后到：乘方最优先，然后是乘除，最后是加减。所以 `2 + 3 * 4` 是 14，不是 20。

拿不准的时候，别背规则，**直接加括号**。括号永远最优先，而且让读代码的人一眼明白你的意图：

```python
result = (2 + 3) * 4    # 你想让加法先算，就明说
```

多写两对括号不丢人，写错优先级才丢人。

## 六、新手第一大坑：数字和文字不能相加

上节课我们干过这件事：

```python
print("很高兴认识你，" + name + "！")
```

文字和文字用 `+` 拼起来，没问题。但数字和文字直接相加，Python 立刻罢工：

```python
>>> age = 25
>>> print("我今年" + age + "岁")
TypeError: can only concatenate str (not "int") to str
```

看到 `TypeError` 别慌，它就是在说：`+` 两边得是同一类东西，一边是文字一边是数字，我不认识这个操作。数字归数字算，文字归文字拼，想把数字塞进一句话里，得先把它变成文字——这就轮到下一节了。

## 七、三种转换：int()、float()、str()

这三个是"变身器"，把值从一种类型换成另一种：

- `str(...)`：变成文字。任何东西都能变
- `int(...)`：变成整数
- `float(...)`：变成小数

先把刚才的坑填上：

```python
>>> age = 25
>>> print("我今年" + str(age) + "岁")
我今年25岁
```

文字也能变数字，前提是它长得确实像数字：

```python
>>> int("25")
25
>>> float("1.75")
1.75
>>> int("abc")
ValueError        # "abc"不像数字，变不了
```

有两个细节要注意，都是实战里真会咬人的：

```python
>>> int(9.99)
9        # 小数变整数是直接砍掉小数部分，不是四舍五入！
```

想要四舍五入，用 `round(9.99)`，它才会给你 10。

## 八、input 的真相：读进来的一律是文字

上节课我们用过 `input()`，这里要揭它的底了：**不管你输入的是文字还是数字，`input()` 给回来的一律是文字**。

写个小实验就明白了：

```python
a = input("第一个数：")   # 你输入 3
b = input("第二个数：")   # 你输入 5
print(a + b)             # 屏幕显示 35，不是 8！
```

你输入 3 和 5，程序却打出 `35`。因为 `a` 和 `b` 手里拿的是文字 `"3"` 和 `"5"`，两个文字用 `+` 是拼接，不是加法。

所以，想拿用户输入的数字做算术，标准姿势是先转换再算：

```python
a = int(input("第一个数："))    # 读进来是文字，立刻转成整数
b = int(input("第二个数："))
print(a + b)                   # 这才是 8
```

这个"`input` 之后接一个转换"的写法，从今天起会出现在你几乎每个程序里，练到闭着眼能写为止。

## 九、课上程序：BMI 计算器

BMI 是衡量体重是否合适的常用指标，算法是体重（公斤）除以身高（米）的平方。现在你手里的零件全齐了：`input` 读入、`float` 转换、乘方、除法。新建 `bmi.py`，敲进去：

```python
# bmi.py —— 输入身高体重，算出 BMI
# 运行方法：python bmi.py

print("BMI 计算器")
print("-" * 20)     # 文字乘数字：把 "-" 重复 20 遍，拼一条分隔线

# input 读进来的永远是文字，身高体重都要参与运算，所以立刻用 float 转换
height = float(input("你的身高是多少米？（例如 1.75）"))
weight = float(input("你的体重是多少公斤？（例如 65）"))

bmi = weight / (height ** 2)   # 括号不能省：先算平方，再做除法

print("你的 BMI 是：" + str(bmi))
print("一般来说，BMI 在 18.5 到 24 之间属于正常范围。")
```

跑起来：

```bash
python bmi.py
```

输入身高 1.75、体重 65，你会看到 BMI 大约是 21.2。

有两个地方值得多看一眼。`print("-" * 20)` 是个小彩蛋：文字乘数字，意思是把这个文字重复几遍，很省事的画线技巧。另外 BMI 那行如果显示出很长的小数尾巴（比如 `21.224489795918183`），不是你写错了——计算机存小数本来就只能存个近似值，怎么把它打印得体面，第 3 课教你收拾。

你可能已经想问：能不能让程序根据 BMI 的值自动说"偏瘦"或"偏胖"？能，而且不难，但需要"判断"这个新本事。那是第 6 课的内容。学完第 6 课欢迎回来改造这个程序，那时你只需要三五行就能让它学会分档说话。

## 新手最常踩的坑

**`TypeError: can only concatenate str ... to str`**

九成是数字和文字直接相加了。检查 `+` 两边，把数字那一侧用 `str()` 包起来，或者看看是不是忘了把 `input` 的结果转成数字。

**输入了数字，程序还是报 `TypeError` 或者算出怪结果**

`input()` 给的永远是文字。回看代码：`input` 外面是不是忘了套 `int()` 或 `float()`。

**`ValueError: could not convert string to float`**

程序要数字，你输入的却不是数字（比如把逗号当小数点输了 `1,75`，或者顺手敲了个汉字）。程序没坏，重新输入就是。

**`NameError: name 'heigth' is not defined`**

变量名拼错了。你把值存进了 `height`，用时却写成 `heigth`，Python 找不到这个盒子。报错信息里的名字往往就是线索，对照着找。

**`0.1 + 0.2` 的结果是 `0.30000000000000004`**

不是你的电脑坏了。计算机存小数用的是近似值，偶尔会露出这样的小尾巴。现阶段知道"这不是 bug"就够了，处理办法以后再说。

## 小结

这节课你带走了四样东西：变量是贴了标签的盒子，`=` 是放进去不是等于；`/` 永远算出小数，`//` 砍掉小数，`%` 取余数，`**` 算乘方；数字和文字不能直接相加，用 `str()`、`int()`、`float()` 先变身；`input` 读回来的一律是文字，要算术就先转。

下一个工具已经排上日程了。下节课我们专门对付文字：怎么取出一段话的某几个字、怎么把大小写统一起来、怎么把乱糟糟的文本收拾成想要的样子——你的程序马上要开始跟大段文字打交道了。
