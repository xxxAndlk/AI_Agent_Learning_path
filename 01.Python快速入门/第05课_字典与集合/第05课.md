# 第 05 课　字典与集合

上节课的购物清单按顺序排列，想拿哪样，报第几个就行。这节课解决另一类更常见的问题：按名字找东西。

想想手机里的通讯录：找张伟的电话，你不会去数"他是第几个联系人"，直接搜名字就行。Python 里干这件事的工具，叫**字典**（dict），它是后面课程里用得最多的容器之一。

---

## 一、从通讯录说起：列表靠位置，字典靠名字

列表靠位置编号取东西，字典靠名字取。名字叫键（key），取出来的东西叫值（value），一对键和值合起来叫一个键值对。

写成代码长这样：

```python
contacts = {"张伟": "13800001111", "王芳": "13900002222"}
print(contacts["张伟"])
```

花括号 `{}` 里，冒号左边是键，右边是值，几对之间用逗号隔开。取值用方括号，注意和列表的区别：列表方括号里放位置数字，字典方括号里放键。

### 新手第一大坑：键不存在，直接取会报错

取一个根本不存在的键，程序会当场停下，报一个 `KeyError`：

```python
print(contacts["赵强"])     # KeyError: '赵强'
```

这个坑几乎每个人都会踩：名字是打进去的，多打一个字母、多个空格，Python 就当不认识。所以查通讯录这种"不确定有没有"的场景，都用 `get()`：

```python
print(contacts.get("赵强"))             # None
print(contacts.get("赵强", "没存"))      # 没存
```

`get()` 查得到就返回值；查不到也不报错，把括号里的第二个参数（兜底值）返回来。什么都不给就返回 `None`，Python 用它表示"这儿什么都没有"。

一句话记住：确定有就用方括号，不确定有没有就用 `get()`。

---

## 二、增、改、删：字典可以随时更新

通讯录要能加人、改号码、删人。这三种操作写起来几乎一样，都是 `字典[键] = 值`：

```python
contacts["陈晨"] = "13600004444"   # 键原来不在 → 新增
contacts["王芳"] = "13811112222"   # 键已经有了 → 改成新号码
```

删除用 `del`，后面跟"字典[键]"：

```python
del contacts["李娜"]
```

数一数存了几个键值对，用 `len()`，和数列表长度一个用法：

```python
print(len(contacts))   # 现在是几对
```

还有一个高频动作：判断某个人在不在。用上节课见过的 `in`：

```python
"张伟" in contacts          # True
"13800001111" in contacts   # False ！
```

第二个结果很多人没想到：`in` 在字典里只认键，不认值。电话号码明明在字典里，它还是返回 `False`，因为它检查的是"名字列表里有没有它"。这和字典的定位一致：你靠名字找东西，不是靠东西找名字。

> 小提示：键必须是"不会变"的东西，字符串、数字都可以，列表不行（放进去会报 TypeError）。记住"名字是写死的"就够了。

另外，从 Python 3.7 起，字典会记住放东西进去的先后顺序，遍历时按这个顺序输出。所以通讯录打印出来和录入顺序一致。

---

## 三、把整本通讯录过一遍：for 与 items()

第 4 课用 `for` 遍历过列表。遍历字典有三种写法，按需要选：

```python
for name in contacts:                  # 直接逛，拿到的是键
    print(name)

for phone in contacts.values():        # 只要值
    print(phone)

for name, phone in contacts.items():   # 键和值都要
    print(f"{name} 的电话是 {phone}")
```

`items()` 最常用：它把每一对键值打包递出来，`for` 一行接住两个变量，一个是键、一个是值。这种"两个变量接两个东西"的写法后面到处都是，现在先见到它。

---

## 四、往卡片里再装东西：嵌套

真实通讯录里，一个人不止有电话，还有城市、邮箱。这时可以让字典的值还是一个字典：外层是"名字 → 卡片"，卡片自己又是一层"项目 → 内容"：

```python
student = {
    "姓名": "小明",
    "分数": [92, 85, 78],                              # 值可以是列表
    "联系方式": {"电话": "13800001111", "城市": "北京"},  # 也可以还是字典
}

print(student["分数"][0])             # 92：先进外层，再按位置取
print(student["联系方式"]["城市"])     # 北京：先进外层，再进里层
```

嵌套不难，就是一层一层往里走：方括号连着写，先说你要哪张卡片，再说卡片里的哪一项。课上的程序用的就是这个结构。

## 五、课上的程序：contacts.py

把这几招串起来，做一个能查、能加、能删的迷你通讯录。新建 `contacts.py`，敲进去：

```python
# contacts.py —— 我的小通讯录
# 外层字典：名字 → 一张"卡片"；卡片本身又是个字典，装着电话和城市

contacts = {
    "张伟": {"电话": "13800001111", "城市": "北京"},
    "王芳": {"电话": "13900002222", "城市": "上海"},
    "李娜": {"电话": "13700003333", "城市": "广州"},
}

print("=== 查电话 ===")
# 用 [] 取不存在的键会当场 KeyError；get() 查不到只会把兜底值递给你
info = contacts.get("王芳", {"电话": "没存", "城市": "没存"})
print("王芳:", info["电话"], "/", info["城市"])

info = contacts.get("赵强", {"电话": "没存", "城市": "没存"})
print("赵强:", info["电话"], "/", info["城市"])   # 根本没这个人，程序也不炸

print()
print("=== 加一个人 ===")
# 键不在就是新增；哪天写重了名字，就成了改他那张卡片
contacts["陈晨"] = {"电话": "13600004444", "城市": "深圳"}
print("现在通讯录里有", len(contacts), "个人")

print()
print("=== 删一个人 ===")
# del 按键删除；删不存在的键会 KeyError，删之前可以用 in 先确认
del contacts["李娜"]
print("李娜已被删除，剩下", len(contacts), "个人")

print()
print("=== 完整通讯录 ===")
for name, info in contacts.items():
    print(f"{name}　{info['电话']}　{info['城市']}")

# 它现在还是"一次性"的：想增删得改代码重跑。
# 第 12 课结业项目里，你会把它升级成真正能交互操作的管理系统。
```

跑起来，输出是这样：

```text
=== 查电话 ===
王芳: 13900002222 / 上海
赵强: 没存 / 没存

=== 加一个人 ===
现在通讯录里有 4 个人

=== 删一个人 ===
李娜已被删除，剩下 3 个人

=== 完整通讯录 ===
张伟　13800001111　北京
王芳　13900002222　上海
陈晨　13600004444　深圳
```

查赵强这一段是本课的重点：查一个不存在的人，程序照样正常跑完，这就是 `get()` 兜底的作用。整个程序没有一句 `while`，因为"问用户要指令、反复执行"要等第 6 课的循环；到时候回头看这个文件，你就知道怎么把它变成真正能操作的通讯录。

## 六、集合：只问"有没有"的花名册

再认识一个工具。看这种需求：你网购了 `["苹果", "香蕉", "苹果", "橘子", "苹果"]` 四单，想知道到底买过哪几样。列表会把苹果报三遍，而你想要的是"就这三种"。

**集合**（set）就是干这个的：它只登记"出现过哪些名字"，写几遍都算一遍，而且不记顺序：

```python
bought = ["苹果", "香蕉", "苹果", "橘子", "苹果"]
unique = set(bought)
print(unique)    # {'橘子', '香蕉', '苹果'}——顺序在你屏幕上可能不同，正常
```

往 `set()` 里一放，重复就全没了，这是集合最常用的功能。有个细节：数字 `5` 和 `5.0` 在集合眼里是同一个东西（值相等就算重复）：

```python
prices = [5.0, 5, 2.5, 8.0, 2.5]
print(set(prices))   # {8.0, 2.5, 5.0}，5 个进去 3 个出来
```

加新东西用 `add()`（注意不是列表的 `append`），判断在不在还是 `in`，集合在这方面很拿手：

```python
marks = {"苹果", "香蕉"}
marks.add("西瓜")
print("西瓜" in marks)   # True
```

集合的另一组常用操作，是求两组数据的集合关系，符号和数学课一致：

```python
a = {"小明", "小红", "小刚"}    # 你的好友
b = {"小红", "小刚", "小美"}    # 她的好友

print(a & b)   # 交集：两人都有的 {'小刚', '小红'}
print(a | b)   # 并集：合并去重 {'小明', '小美', '小红', '小刚'}
print(a - b)   # 差集：只在 a 里的 {'小明'}
```

`&` 是交集：两个人都加过的好友；`|` 是并集：只要有一个人加过就算；`-` 是差集：我有的你没有。找共同好友、找重复文件名、对比两份名单的差异，都会用到这三个符号。

---

## 七、什么时候用哪个

三个容器都认识了，选之前先确定：靠什么找东西。

- 靠顺序、位置找（"第 3 个"），东西可能重复，用列表
- 靠名字、编号找（"张伟的电话"），一查一个准，用字典
- 不关心顺序，只关心"有没有"和"重不重复"，用集合

---

    A[你报一个键] --> B{键在字典里吗}
