## 1 技术简介

Python 是目前全球最流行的编程语言之一，以**语法简单、易读易学、生态强大**著称，广泛应用于：

- **AI 与机器学习**：PyTorch、TensorFlow 等主流框架都以 Python 为第一语言
- **数据分析**：pandas、NumPy 是数据处理的行业标准
- **Web 开发**：Django、FastAPI 可快速搭建网站与接口
- **自动化脚本**：批量处理文件、操作 Excel、定时任务等

本书后续所有章节（AI 基础、LangChain、RAG、Agent 等）的示例代码全部使用 Python 编写。本章面向**零基础读者**，目标只有一个：装好 Python、跑通第一个程序、学会管理项目的依赖环境——这是整条学习路径的地基。

### 核心特性

- **解释执行**：写完就能运行，不需要编译，改一行看一行结果，反馈快
- **动态类型**：变量无需声明类型，代码简短，接近自然语言
- **"自带电池"**：标准库内置文件、网络、JSON、日期等常用能力，开箱即用
- **跨平台**：Windows、macOS、Linux 上代码几乎完全一致

### 解决的问题

- 想进入 AI 应用开发，但不知道从哪门语言、哪个环境开始
- 网上教程五花八门，装完 Python 却在命令行里处处报错
- 项目之间依赖的库版本互相冲突，装 A 坏 B

本章按"安装 → 验证 → 虚拟环境 → 第一个程序"的顺序，一次把地基打好。

## 3 核心概念

### 3.1 解释器与 REPL

- **解释器（Interpreter）**：真正执行 Python 代码的程序。安装 Python = 安装解释器
- **REPL（交互式环境）**：在终端输入 `python` 回车后进入的"你一句我一句"对话模式，适合试验小段代码；输入 `exit()` 退出

### 3.2 pip 与 PyPI

- **PyPI**：Python 的公共"应用商店"，托管几十万个第三方库
- **pip**：从 PyPI 安装库的命令行工具，随 Python 一起安装

```bash
pip install requests        # 安装
pip list                    # 查看已安装
pip install -U requests     # 升级
```

### 3.3 虚拟环境（venv）

不同项目可能依赖同一个库的不同版本（A 项目要 pandas 1.x，B 项目要 2.x）。**虚拟环境**为每个项目创建一份独立的库目录，互不干扰——这是 Python 开发的标准做法：

- 每个项目一个虚拟环境，激活后 `pip install` 只装进当前环境
- 本书第 3 章之后的所有实战项目都假设你已为项目建好虚拟环境

### 3.4 代码编辑器

推荐 **VS Code**（免费、中文界面、对 Python 支持最好）：

1. 官网下载安装 VS Code
2. 扩展市场搜索并安装 **Python** 扩展（微软官方）
3. 打开任意 `.py` 文件即可获得语法高亮、自动补全、一键运行

## 4 工作原理

Python 程序的执行过程：

```text
hello.py（源码）
   │  解释器启动，先编译为字节码
   ▼
字节码（.pyc 缓存）
   │  Python 虚拟机逐条解释执行
   ▼
程序输出结果
```

- 源码文件即文本文件，后缀 `.py`，可用任何编辑器打开
- 首次运行会生成 `__pycache__` 目录存放字节码缓存，加速后续导入
- REPL 模式省去文件环节，输入一行立即执行一行

## 5 技术实现

### 5.1 Windows 安装

1. 打开官网 <https://www.python.org/downloads/>，点击下载 Python 3.12+
2. 运行安装程序，**务必勾选底部 "Add python.exe to PATH"**，再点 Install Now
3. 安装完成后按 `Win + R` 输入 `cmd` 打开命令提示符，验证：

```bash
python --version
# Python 3.12.x
```

> 若提示"'python' 不是内部或外部命令"，说明没有勾选 PATH，最简单的办法是卸载后重装并勾选；或按第 7 节排错。

### 5.2 macOS 安装

```bash
# 方式一：官网下载 .pkg 安装包，双击安装
# 方式二：使用 Homebrew
brew install python@3.12
python3 --version
# Python 3.12.x
```

macOS 自带的 `python3` 可能版本较旧，建议官网或 Homebrew 安装新版。

### 5.3 验证安装

```bash
python --version      # 查看版本（macOS/Linux 用 python3）
pip --version         # 确认 pip 可用
```

### 5.4 创建并使用虚拟环境

为每个项目建立独立环境（以本书实战项目为例）：

```bash
# 1. 在项目目录下创建虚拟环境（一次性）
python -m venv venv

# 2. 激活
# Windows（cmd）:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 3. 激活后命令行前会出现 (venv) 标记，此时安装的库只属于本项目
pip install requests

# 4. 退出虚拟环境
deactivate
```

> 记住两条铁律：**先激活、再安装**；`venv/` 目录不提交到 git（加入 .gitignore）。

### 5.5 运行第一个程序

新建 `hello.py`，输入一行代码并运行：

```bash
python hello.py
# 你好，Python！
```

三种运行方式对比：

| 方式 | 命令 | 适用场景 |
|------|------|----------|
| 交互式 REPL | `python` 回车 | 试验一两行代码 |
| 脚本运行 | `python hello.py` | 日常开发（最常用） |
| IDE 一键运行 | VS Code 右上角 ▶ | 调试、断点 |

## 6 Python代码实现与逐行解析

### 6.1 第一个程序：hello.py

```python
# hello.py —— 第一个 Python 程序
print("你好，Python！")          # print() 把内容输出到屏幕，字符串用引号包住
print("3 + 5 =", 3 + 5)          # print 可以一次输出多项，逗号分隔，自动加空格
```

逐行解析：

- 第 1 行以 `#` 开头是**注释**，给人看，解释器忽略
- 第 2 行调用内置函数 `print()`，引号内是**字符串（str 类型）**
- 第 3 行先计算 `3 + 5`，再把 `3 + 5 =` 与结果 `8` 一起打印

### 6.2 一个能交互的小程序

```python
# guess.py —— 猜数字：体验变量、输入、分支
secret = 7                       # 变量赋值：不需要声明类型
guess = int(input("猜一个1~10的数字："))   # input() 读入的是字符串，int() 转成整数

if guess == secret:              # if 分支：注意结尾的冒号和缩进
    print("猜对了！")
elif guess < secret:
    print("小了，再试试")
else:
    print("大了，再试试")
```

要点：

- `input()` 的返回值永远是字符串，参与数学运算前必须用 `int()`（或 `float()`）转换
- Python **用缩进表示代码块**（约定 4 个空格），冒号 `:` 开启块
- `==` 是比较相等，`=` 是赋值

### 6.3 环境自检脚本

```python
# check_env.py —— 一键自检学习环境
import sys                       # sys：解释器相关信息
import platform                  # platform：操作系统信息

print("Python 版本:", sys.version.split()[0])
print("操作系统:", platform.system(), platform.release())
assert sys.version_info >= (3, 10), "请升级到 Python 3.10 以上！"
print("✅ 环境正常，可以开始学习本书第 1.2 节了")
```

逐行解析：

- `import` 导入标准库模块，无需安装
- `sys.version.split()[0]` 取出版本号首段（如 `3.12.4`）
- `assert` 断言：条件不满足就抛出提示，用于环境门槛检查

## 7 常见问题

### 7.1 'python' 不是内部或外部命令

- **原因**：安装时未勾选 Add to PATH，终端找不到解释器
- **解决**：重装并勾选；或手动把 Python 安装目录加入系统环境变量 PATH；Windows 商店版可直接在"管理应用执行别名"里关闭干扰项

### 7.2 多版本共存导致装错地方

- **现象**：`pip install` 成功，运行时却 `ModuleNotFoundError`
- **原因**：机器上有多个 Python，`python` 和 `pip` 指向不同版本
- **解决**：统一用 `python -m pip install xxx`（保证 pip 与 python 是同一个），并养成每个项目用 venv 的习惯

### 7.3 pip 安装慢或超时

- **原因**：默认从国外 PyPI 下载，网络慢
- **解决**：使用国内镜像源

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple requests
# 或设为默认：
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 7.4 中文输出乱码（Windows）

- **原因**：老版 cmd 默认 GBK 编码
- **解决**：Windows 10/11 建议直接使用 Windows Terminal 或 PowerShell；cmd 中可先执行 `chcp 65001` 切换到 UTF-8

### 7.5 venv 激活报错"禁止运行脚本"（PowerShell）

- **原因**：PowerShell 默认执行策略限制
- **解决**：管理员 PowerShell 执行一次 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`，或改用 cmd 激活
