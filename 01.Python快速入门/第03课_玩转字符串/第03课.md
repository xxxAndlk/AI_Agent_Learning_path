# 第 03 课　玩转字符串

上一课我们让程序记住了变量、会算数了。这一课轮到文字：你手机里的每条消息、网页上的每段话，在程序眼里都是字符串。别觉得文字比数字简单——把一段乱糟糟的文本收拾得整整齐齐，恰恰是程序最常干的活之一。

这节课结束时，你会亲手写一个小工具：输入一段话和一个词，它帮你清理空格、换掉旧词、打印一份处理报告。

---

## 一、字符串是什么：排好队的一串字符

字符串（string），说白了就是**一串字符手拉手排好队**。

把它想成一列火车：每节车厢坐着一个字符，车头到车尾连起来就是完整的文字。比如 `"Python"` 就是 6 节车厢，每节装一个字母。要注意，空格和标点也是正经乘客——`"你好 世界"` 这列火车上有 5 节车厢：四个汉字，加中间那个空格。

在 Python 里，只要用引号包起来，一段文字就成了字符串，可以存进变量：

```python
name = "小明"
letter = 'A'
sentence = "今天天气不错"
```

## 二、引号的三种用法

单引号和双引号在 Python 里完全等价，`"abc"` 和 `'abc'` 是同一个字符串。那为什么留两种？为了**互相搭救**。

想表达这样一句话：`他说："你好"`。句子本身带双引号，外面再用双引号包就撞车了，Python 会分不清哪里是结尾。两种解法：

```python
# 解法一：外面换单引号，里外不打架
words = '他说："你好"'

# 解法二：给里面的双引号加个 \ 通行证，下一节细讲
words = "他说：\"你好\""
```

第三种是**三引号**，专门管跨行。普通字符串一换行就报错，三引号里的内容可以原样写好几行：

```python
poem = """床前明月光，
疑是地上霜。"""
print(poem)
```

打印出来就是两行诗，连换行都替你保留好了。

## 三、拼接与重复：+ 和 *

文字也能做"加法"，用 `+` 把几段接在一起：

```python
first = "好好"
second = "学习"
print(first + second)        # 好好学习
print("我今年" + "18" + "岁")   # 我今年18岁
```

注意一个新手高频报错：`+` 两边必须都是字符串。写 `"我今年" + 18` 会直接报错，因为 18 是数字，文字和数字不能相加。要先把数字用 `str()` 换成文字：`"我今年" + str(18)`。

乘号 `*` 用在字符串上意思是"重复几遍"：

```python
print("ab" * 3)        # ababab
print("-" * 20)        # 打一条分隔线，很常用
```

## 四、量一量长度：len()

`len()` 用来数一个字符串有几个字符，空格和标点都算在内：

```python
print(len("hello"))      # 5
print(len("你好 世界"))    # 5：四个字符加一个空格
print(len(""))           # 0：空字符串一个字符都没有
```

顺带认识一下空字符串 `""`：引号里什么都没有，但它是合法的字符串，就像一列没有车厢的火车。

## 五、索引与切片：挑出你想要的那一段

这是本节课最重要的部分，值得慢下来多看两遍。

### 索引：报车厢号

字符串里的每个字符都有自己的编号，这个编号叫**索引**。规矩只有一条：**从 0 开始数**。第一个字符是 0 号，不是 1 号——全世界的编程语言几乎都这么定，记住就好。

```python
word = "Python"
#       P  y  t  h  o  n
# 正着数 0  1  2  3  4  5
# 倒着数-6 -5 -4 -3 -2 -1

print(word[0])     # P，第一个
print(word[3])     # h
print(word[-1])    # n，倒数第一个
print(word[-2])    # o，倒数第二个
```

方括号跟在字符串（或存了字符串的变量）后面，就是"把几号车厢里的乘客交出来"。负数是从车尾往前数，`-1` 永远是最后一个，很好用。

用错编号会怎样？`word[10]` 这种不存在的号，Python 会报 `IndexError`，意思是"没有这节车厢"。

### 切片：切下一段

一次要一个字符不够用，更多时候你想要一段，这就要用**切片**：`[起:止]`。

```python
word = "Python"
print(word[1:4])    # yth：从 1 号取到 4 号【之前】
print(word[:3])     # Pyt：从头取到 3 号之前
print(word[2:])     # tthon 后半段：从 2 号取到结尾
print(word[:])      # Python：头尾都不写，就是全部
```

新手最需要在脑子里钉死的一条规矩：**含头不含尾**。`word[1:4]` 拿到的是 1、2、3 号，不包括 4 号。

可以这么想：切面包的时候，`[1:4]` 的意思是"在第 1 片之前下第一刀，在第 4 片之前下第二刀"——两刀之间夹住的是 1、2、3 这三片。终点那个号是"刀落下的位置"，不归你。

还能加第三个数：**步长**，表示"隔几个取一个"：

```python
print(word[::2])     # Pto：从头到尾，每 2 个取 1 个
print(word[::-1])    # nohtyP：步长 -1，倒着走，整句反转！
```

`[::-1]` 值得单独记住：头尾省略、步长 -1，效果就是把整个字符串翻个面。后面练习会用到它。

切片比索引宽容得多：`word[3:100]` 越界了也不报错，有多少给多少，绝不多给。

## 六、字符串的常用招式

字符串自带一批"招式"（术语叫方法），写法都是 `字符串.招式名()`。这里挑最常用的八个，每个都值得一试。

```python
s = "  Hello, World!  "

# upper / lower：整体变大写、变小写
"abc".upper()          # 'ABC'
"ABC".lower()          # 'abc'

# strip：剪掉【两头】的空格，中间的不管
s.strip()              # 'Hello, World!'，两头的空格没了

# replace：把旧词全部换成新词
"猫吃鱼".replace("猫", "狗")     # '狗吃鱼'

# split：按分隔符切开，得到一段段的列表
"苹果,香蕉,橘子".split(",")       # ['苹果', '香蕉', '橘子']
"zhang san feng".split()         # 括号里不写，就按空格切

# join：split 的反操作，把一串字符串用指定字符缝起来
", ".join(["张三", "李四"])       # '张三, 李四'

# find：找旧词出现的位置，返回的是索引；找不到返回 -1
"hello".find("ll")     # 2（l 出现在 2 号位置）
"hello".find("z")      # -1，注意：找不到不报错，只给你 -1

# startswith：判断是不是以某个词开头，答案是 True 或 False
"hello".startswith("he")    # True
```

split 切出来的一大段、join 缝起来的一整段，这种"装着好几个字符串"的东西叫列表，是下一课的主角，这里先混个脸熟。

### 它们有个共同脾气：原件不动，只给副本

这是新手最容易困惑的地方，专门讲一遍。

字符串是**不可变**的——已经造出来的字符串，一个字符都改不了。所有方法都不会动原件，而是**照着原件加工一份新的还给你**。就像去复印店：你在复印件上怎么改都行，原稿始终躺在包里没变。

```python
s = "hello"
s.upper()
print(s)          # 还是 hello！方法的结果没接住，就丢了

s = s.upper()     # 用 s = 接住新字符串，重新装回 s 这个盒子
print(s)          # HELLO
```

第一处 `s.upper()` 白算了：新字符串造出来了，但没人接住它。第二处用 `s =` 把新字符串存回变量，看起来"s 变了"，其实是盒子里的旧字符串被换成了新造的，旧的那个本身从头到尾没被改过一个字。

理解了这一点，"方法链"就好懂了：方法返回新字符串，新字符串还能继续调方法，像流水线一样一环扣一环：

```python
dirty = "  Hello, World!  "
clean = dirty.strip().lower().replace("!", "?")
print(clean)      # hello, world?
```

读法：先对原件 strip，得到副本一；对副本一 lower，得到副本二；再对副本二 replace，得到最终结果。原件 `dirty` 全程没动。

## 七、转义字符：给特殊字符开通行证

有些字符在字符串里有特殊身份，比如 `\n` 是"换行"，`\t` 是"跳到下一个制表位"（可以理解成按了一下 Tab 键）。它们看不见摸不着，但真实存在，`len()` 也会把它们数进去。

想在文字里表示这些"特殊身份的字符"，就在前面加一个反斜杠 `\`，这叫**转义字符**——意思是"此字符不走寻常路"：

```python
print("第一行\n第二行")       # \n 处换行，输出占两行
print("姓名：\t小明")         # 中间隔开一段距离
print("他说：\"你好\"")       # \" 就是普普通通的一个双引号
```

`\n` 特别常用。而 `\"` 解决的就是第二节那个引号撞车问题：让 Python 明白"这个引号是内容，不是字符串的结尾"。

还有个坏消息：反斜杠从此也成了特殊字符。想打印一个正经的反斜杠，得写两个 `\\`。

## 八、f-string 进阶：把变量嵌进文字里

第一课你见过 `print("很高兴认识你，" + name + "！")` 这种拼法。能用，但引号加号满天飞，句子一长就乱。更顺手的工具是 **f-string**：在引号前加个 `f`，花括号里直接写变量名，Python 会把变量里的值填进去：

```python
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")     # 我叫小明，今年18岁
```

花括号里还能做简单加工。两个最常用的：

```python
price = 3.5
print(f"总价：{price:.2f} 元")        # 总价：3.50 元 —— .2f 表示保留两位小数

word = "abc"
print(f"[{word:>10}]")               # [       abc] —— >10 表示占 10 格、靠右站
```

`{price:.2f}` 读作"把 price 按两位小数的格式填进来"；`{word:>10}` 读作"给 word 留 10 个格，靠右对齐"（`<` 就是靠左）。对齐这招在做表格、打报告时特别好用，下面的选做练习会让你用它。

## 九、课上动手：text_tool.py

来做个完整的小工具。它问你要一段句子、一个旧词、一个新词，然后去掉句子首尾的空格、数一数长度、把旧词换成新词，最后打一份整齐的报告。

新建 `text_tool.py`，敲入下面的代码：

```python
# text_tool.py —— 文本处理小工具：清空格、数字数、换词，最后出报告
# 运行：在终端里输入 python text_tool.py，按提示一句一句输入

sentence = input("请输入一段句子：")
old_word = input("想把哪个词换掉？")
new_word = input("换成什么？")

clean = sentence.strip()              # 剪掉首尾空格；中间的空格是有用的，不动
count = len(clean)                    # 数整理后的句子有多少字符
result = clean.replace(old_word, new_word)   # 旧词不在句子里时，replace 什么都不换，也不报错

print()
print("========== 处理报告 ==========")
print(f"原句　　：{sentence}")
print(f"整理后　：{result}")
print(f"字符数　：{count}（含空格）")
print(f"替换　　：{old_word} -> {new_word}")
print("==================================")
```

跑起来，试一次这样的输入（输入内容用「」标出）：

```text
请输入一段句子：「   我今天学会了字符串切片   」
想把哪个词换掉？「切片」
换成什么？「拼接」
```

输出：

```text
========== 处理报告 ==========
原句　　：   我今天学会了字符串切片
整理后　：我今天学会了字符串拼接
字符数　：11（含空格）
替换　　：切片 -> 拼接
==================================
```

对着代码读三处细节：报告开头的空 `print()` 是为了空一行，让输出不挤；`字符数` 数的是**整理后**的句子，所以原句里那几个首尾空格没被算进去；报告里每个冒号后都对得整整齐齐，靠的就是 f-string 的原样填充——中文全角字符天生等宽，排出来自然齐。

## 十、新手最常踩的坑

**`IndexError: string index out of range`**

索引越界：报了一个不存在的车厢号。先用 `len()` 看看字符串多长，编号最大只到 `len(s) - 1`。注意切片越界不报错，只有单个索引越界才报。

**`SyntaxError: unterminated string literal`**

字符串没关上门：引号少了半个，或者句子里有没转义的同类引号。检查引号是否成对，句子内含引号就换一种引号来包，或加 `\"`。

**`TypeError: can only concatenate str ...`**

`+` 两边一个是文字一个是数字。把数字用 `str()` 包一下再相加。

**方法调了却"没效果"**

`s.upper()` 之后打印 `s` 还是老样子——方法的结果被扔了。记得用 `s = s.upper()` 接住新字符串。字符串方法永远不改原件。

**`find` 找明明存在的词却得到怪数字**

`find` 返回的是**位置编号**不是第几个：位置 0 就是"第 1 个"。返回 -1 表示没找到。

**数字被当成文字数了**

`input()` 给你的**永远是字符串**。输入 25，拿到的是 `"25"`，`len()` 会告诉你它是 2 个字符。想当数字用要 `int()`（上一课讲过），想数长度就直接 `len()`。

## 小结

这节课的装备清单：三种引号（撞车时换着用、跨行用三引号）、`+` 和 `*`、`len()`、索引与切片（含头不含尾，`[::-1]` 反转）、八个常用方法、转义字符 `\n` `\t` `\"`、f-string 的变量填充与简单格式。

如果只让你记一句话，记这条：**字符串不可变，方法只还新副本**。想留住结果，就用 `=` 接住它。

字符串常常一大段一大段地来，split 切出来的词、input 来的一行行文字，总得有个地方放。下一课的主角就是那个能装一串东西的容器：列表。我们会用它做一个能添能删的购物清单。
