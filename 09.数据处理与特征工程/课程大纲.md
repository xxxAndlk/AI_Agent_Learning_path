# 数据处理与特征工程 · 课程大纲

有一句在 AI 行业流传很广的话：垃圾进，垃圾出。意思是喂给模型的数据质量，基本决定了最终效果的上限。无论模型多强、算法多巧，喂进去的是一堆混乱、错误、没代表性的数据，出来的结果也不会好。

这一章我们专门和"数据"打交道：怎么把原始、脏乱的数据清洗成能用的样子；怎么从一大堆信息里挑出真正有用的特征；数据不够时怎么合理地"变出"更多样本；以及在大模型时代，怎么用 LLM 来帮我们构建和加工数据。这一章动手多、工具实用，也是很多岗位日常最耗时的工作。

## 学习之前

- 已掌握 Python 基础，会读写文件、用列表字典、处理异常
- 本章会用到 pandas 等工具，我们会在文件头注明安装命令；用小数据集练习，本机可跑
- 不要求统计学基础，所有概念都会用大白话和例子讲清楚

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | 数据清洗与预处理 | 缺失值、重复值、异常值、格式不统一怎么处理；为什么清洗往往最花时间 |
| 第 02 课 | 特征提取与选择 | 什么是特征；怎么把原始信息变成模型能用的特征；如何剔除没用甚至添乱的特征 |
| 第 03 课 | 数据增强技术 | 数据不够时怎么办；文本里的同义替换、回译等增强手段及其风险 |
| 第 04 课 | LLM 数据工程 | 用大模型批量生成、改写、标注、质检数据；指令数据与 RAG 数据怎么造 |

## 怎么学

1. 第 01 课用一份"故意弄脏"的小数据跟着清洗，每处理一类问题都想想"不处理会怎样"
2. 特征工程是传统机器学习的核心手艺，本章先建立直觉，不必死记方法清单
3. 数据增强务必记住边界：增强是为了增加多样性，乱增强反而会引入噪声和错误
4. 第 04 课是大模型时代的新工作方式，注意"让 LLM 干批量脏活、人来定规则和抽检"的分工
