# 模型部署与推理优化 · 课程大纲

到目前为止，你写的程序主要在自己电脑上、用别人的 API 跑。可真实场景里还有另一类问题：公司想把一个开源大模型部署在自己的服务器上，既要响应快，又要省钱，还要能同时服务很多用户。这时就进入了"模型部署与推理优化"的世界。

这一章我们解决一连串工程问题：训练好的模型怎么导出和转换格式；怎么通过量化让它占更小内存、跑得更快；推理引擎在底层做了哪些优化；大模型专用的推理框架（如 vLLM、Ollama）怎么用；最后怎么把模型包装成一个稳定可调用的服务。这一章偏后端和系统，是 AI 工程师区别于"只会调 API"的重要分水岭。

## 学习之前

- 建议已学完前面的工程章节，理解模型、推理、token 等概念
- 本章部分内容涉及服务器、GPU，本机未必都能实操，我们会明确区分"能跟着跑的"和"建立概念即可的"
- 不必害怕底层名词，核心主线很简单：**在有限的硬件上，让模型又快又省又稳地服务更多人**

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | 模型导出与格式转换 | 模型文件里到底存了什么；state_dict、ONNX 等格式；为什么要转换 |
| 第 02 课 | 模型量化技术 | 用更低精度表示参数为什么能省内存提速；PTQ、各种比特位宽的取舍 |
| 第 03 课 | 推理引擎与优化 | 算子融合、内存优化、批处理等底层加速手段的直觉 |
| 第 04 课 | LLM 推理框架 | vLLM、Ollama、TGI 等框架解决什么；PagedAttention、连续批处理的直觉 |
| 第 05 课 | 模型服务化 | 把模型包成 API 服务；模型网关、路由、限流、扩缩容的基本思路 |

> 本机实操锚点：第 04 课的 Ollama 在自己电脑上装好就能跑开源模型，是本章人人可动手的落点，学到那儿务必亲手试一次。

## 怎么学

1. 始终抓住"用什么资源、换什么收益"这条主线——每个技术都是在速度、显存、精度、成本间做交换
2. 第 02 课量化和第 04 课推理框架是本章重点，也是当前业界最常用的技能
3. 概念性内容（GPU、集群）先建立地图，等真正接触项目时再深入
4. 部署是系统工程，第 05 课要体会"模型只是服务的一部分"，稳定性和运维同样关键
