# 代码示例：01.Python快速入门

与《01.Python快速入门》各文档配套的可运行示例。**目录结构与文档章节同构**，按小节号即可从文档定位到代码。

## 目录结构约定

```
代码示例/01.Python快速入门/
├── 1.1_Python入门与环境搭建/          # 入门示例（仅3个，直接平铺）
│   ├── 01_hello.py                    # 第一个程序（对应 1.1 §6.1）
│   ├── 02_guess.py                    # 猜数字：变量/输入/分支/循环
│   └── 03_check_env.py                # 环境自检脚本
└── 1.2_Python基础语法/
    ├── 2_技术背景/                    # 对应文档「## 2 技术背景」
    ├── 3_核心概念/                    # 对应文档「## 3 核心概念」
    │   ├── 3.1_变量与数据类型.py      # 文件名 = 文档小节号_标题
    │   ├── 3.9.4_生成器应用场景.py
    │   └── 3.9.4_生成器应用场景_2.py  # 同一小节多个代码块 → 追加 _2、_3…
    ├── 4_工作原理/
    ├── 5_技术实现/
    ├── 6_代码实现与解析/
    ├── 7_常见问题/
    └── 8_应用场景/
```

## 命名规则

- **文件名 = 文档小节号_小节标题.扩展名**，如 `3.8_装饰器.py` 对应 1.2 文档的 §3.8
- 同一小节有多个代码块时，按文档出现顺序追加 `_2`、`_3`（第一个不带序号）
- 1.6 的文档大纲编号与全书模板不同（含 9~13 大节与"快速参考卡"），子目录按其真实大节命名
- 演示**故意报错**的示例（如 1.2 `7.6_缩进错误.py`）运行报错属预期，用于对照讲解

## 如何运行

```bash
# 建议先完成 1.1 的环境搭建（Python 3.12+）
cd 代码示例/01.Python快速入门/1.2_Python基础语法/3_核心概念
python 3.1_变量与数据类型.py
```

- 大多数示例仅依赖标准库，可直接运行；需第三方库的示例在文件头部注释中注明
- Windows 终端若中文乱码，先执行 `chcp 65001`（见 1.1 §7.4）
