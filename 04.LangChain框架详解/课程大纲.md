# LangChain 框架详解 · 课程大纲

第 03 章你已经能用原生 SDK 调用大模型、写提示词、挂工具、收结构化结果了。你可能也发现了：稍微复杂一点的应用，就要自己处理一堆琐碎事——多步串联、记忆历史、换模型、管工具、解析输出、出错重试。

LangChain 就是来帮你少写这些样板的。它把大模型应用里反复出现的零件都做好了，还提供一种叫 LCEL 的"搭积木"方式，让你像接水管一样把各个环节拼起来。这一章我们不只学 API，更要搞懂每个零件解决什么问题、什么时候该用、什么时候干脆别用框架。

## 学习之前

- 务必先学完第 03 章，能独立用 SDK 完成一次带工具的调用
- 本章代码较多，建议每课建一个文件跟着敲，框架更新很快，遇到行为差异以官方文档为准
- LangChain 只是工具，理解它封装的底层逻辑比记住函数名重要得多

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | LangChain 是什么 | 组件、链、Runnable、整体架构；它到底替你省了什么；安装与最小示例 |
| 第 02 课 | LCEL：用管道搭积木 | Runnable 接口、竖线管道、顺序与并行、输入输出映射、自动重试 |
| 第 03 课 | Memory：让模型记得前文 | 为什么默认"失忆"；缓冲、窗口、摘要几种记忆的取舍与适用场景 |
| 第 04 课 | Tools 与 Agent | 把工具交给模型；Agent 如何自己决定一步步调用工具完成任务 |
| 第 05 课 | Retrievers：接上检索 | Document 与检索器；向量检索如何嵌进链条；常见高级检索器直觉 |
| 第 06 课 | 输出解析器 | 让框架帮你把模型回答解析成对象；解析失败怎么办 |
| 第 07 课 | 综合实战 | 把 LCEL、记忆、工具、检索串成一个完整小应用，并讨论框架的边界 |

## 怎么学

1. 每学一个组件，先问"不用它我自己要怎么写"，再看它怎么帮你省事
2. LCEL 的管道写法是本章核心，务必亲手拼几条不同的链
3. 版本提醒：LangChain 演进较快，导入路径和写法可能变化，课程会标注关键版本，跑不通时先查官方迁移指南
4. 第 07 课会讨论"什么时候不该用 LangChain"，保持独立判断，别为了用框架而用
