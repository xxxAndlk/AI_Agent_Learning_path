# AI 底层基础 · 课程大纲

这一章不写代码、不教框架，专门回答一个问题：**AI（尤其是能和你聊天的大模型）到底是怎么工作的？**

你将看到的机器学习、神经网络、注意力机制、Transformer 这些词，听起来吓人，其实背后都是很朴素的道理。我们会用生活里的例子一个一个拆开，再配上示意图。学完这章，你再去用大模型、看 AI 相关的文章，心里会有一张清楚的地图，而不是一堆看不懂的名词。

先别急着跳过这章"纯理论"：后面第 5 章的检索、第 6 章的 Agent，全都踩在这章的概念上。在这里把地基打牢，往后每学一章都会明显省力——这就是它最大的用处。

## 学习之前

- 建议先学完第 01 章 Python 入门（这一章虽然不写代码，但偶尔会出现极短的代码片段，看懂即可）
- 准备纸笔：这章概念一环扣一环，随手画一画关系图，比单纯看效果好
- 不要求数学：所有公式都会用大白话解释，你需要的是耐心和想象力，不是演算能力

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | AI 到底是什么 | AI、机器学习、深度学习、大模型这几个词的关系；"让机器自己学"和传统编程有什么不同 |
| 第 02 课 | 机器学习基础 | 机器怎么从数据里总结规律；三种学习方式；为什么有时"学得太死"反而考不好 |
| 第 03 课 | 神经网络 | 一个"神经元"在干什么；为什么要一层叠一层；机器靠什么知道自己错了 |
| 第 04 课 | 深度学习是怎么练出来的 | 损失、梯度、优化器：看机器像蒙着眼下坡一样一步步变好 |
| 第 05 课 | 文字怎么变成数字 | 分词与 Embedding：机器不认识字，它只认识数字 |
| 第 06 课 | 注意力机制 | 读一句话时，机器怎么知道该"重点看"哪几个词 |
| 第 07 课 | Transformer | 当今几乎所有大模型共用的骨架长什么样 |
| 第 08 课 | 大模型怎么"说"出回答 | 预训练、一个词一个词往外蹦、温度、以及它为什么会"记不住"太长的话 |
| 第 09 课 | 模型微调 | 已经很聪明的模型，怎么再教它专精某一行；LoRA 为什么省钱 |
| 加餐课 | AI 工程里的 Python | 装饰器讲透，异步和生成器做个快速复习；附录补一点数据结构直觉 |

## 怎么学

1. 每课开头的示意图先花十秒看明白，再读文字
2. 课末的"想一想"先自己回答，别急着往下翻
3. 看不懂某一节很正常，做个记号往后走，等整章读完再回头，常常会突然通了
4. 每学完一课，试着用自己的话把它讲给一个完全不懂的朋友听——讲不明白的地方，就是还没真正懂的地方
