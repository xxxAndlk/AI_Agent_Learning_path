# Multi-Agent 协作与企业助手（第 06 课实战项目）

## 这是干什么的

一支分工明确的 Agent 团队：主管把企业需求拆成子任务，派给检索员/分析员/文案三位"专科工人"，收结果、自检补派，最后汇总成一份带依据的企业报告（企业助手形态）。

## 怎么装

零依赖：装好 Python 3.9+ 即可，不需要 pip install 任何东西。

## 怎么跑

```
python multi_agent_app.py                    # 内置演示：季度营收简报
python multi_agent_app.py "写一份新员工入职指引"  # 换需求再看一条执行路径
```
