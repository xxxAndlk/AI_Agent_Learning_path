# 智能客服机器人（第 03 课实战项目）

## 这是干什么的

命令行里的客服机器人：识别用户意图（问候/咨询/投诉/其他），咨询类自动查知识库，按固定口吻模板回复；查不到就诚实转人工，绝不编造制度。

## 怎么装

零依赖：装好 Python 3.9+ 即可，不需要 pip install 任何东西。

## 怎么跑

```
python customer_service.py        # 进入对话，输入 q 退出
python customer_service.py demo   # 自动轮播三类典型对话
```

试这三句感受分流：`在吗`（问候）、`差旅报销有什么要求`（查库）、`你们这系统也太烂了吧`（安抚）。
