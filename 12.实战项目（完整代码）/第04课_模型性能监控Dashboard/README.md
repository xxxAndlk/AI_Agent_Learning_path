# 模型性能监控 Dashboard（第 04 课实战项目）

## 这是干什么的

命令行版模型调用监控：采集每次调用的延迟、token、成败，聚合成一张报告（成功率/平均延迟/P95/均值 token），成功率或 P95 越过阈值自动点名告警。承接第 11 章的监控与可观测性。

## 怎么装

零依赖：装好 Python 3.9+ 即可，不需要 pip install 任何东西。

## 怎么跑

```
python monitor_dashboard.py                # 模拟数据全流程：报告 + 告警
python monitor_dashboard.py ask "翻译这段话"  # 单次调用的采集与统计演示
```

内置演示故意埋了两个问题调用：ocr_api（成功率低）、summarize（P95 超标），跑一次就能看到告警被触发。
