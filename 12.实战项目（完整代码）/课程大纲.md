# 实战项目 · 课程大纲

光学不练假把式。前面的章节让你掌握了一个个零件，这一章我们把它们组装成完整、能跑、贴近真实工作的项目。每个项目都会明确：它解决什么真实问题、整体怎么设计、一步步怎么实现、做完怎么扩展。

这一章是全路线的"练兵场"，也是作品集的主要来源。建议每个项目都亲手做出来、跑通，并尝试改成你自己的版本——面试和实际工作中，能讲清楚一个亲手做过的项目，比罗列十个学过的名词有说服力得多。

**结构声明：** 本章每个项目都先交付 CLI / 库形态的核心逻辑——命令行能跑通、能当模块复用，这就是主体。Streamlit、FastAPI、网页界面这些"门面功夫"，是学完第 14 章后回来加的扩展环节，到时候再给项目穿衣服，又快又顺。

## 学习之前

- 已学完第 03～11 章的核心内容，会调用模型、搭链、做检索、接工具
- 项目会综合用到前面的知识，遇到不熟的地方及时回看对应章节
- 我们会优先做"小规模、本机可跑"的版本，再说明如何扩展到生产

## 课次安排

| 课次 | 主题 | 你会做出的东西 |
|------|------|--------------|
| 第 01 课 | 本地知识库 RAG | 喂给它几份文档，就能基于文档准确问答、给出处的小系统 |
| 第 02 课 | Agent 任务执行系统 | 能自主拆解任务、调用工具、一步步把事办完的智能体 |
| 第 03 课 | 智能客服机器人 | 能理解用户问题、查知识库、按口吻回复的客服 Demo |
| 第 04 课 | 模型性能监控 Dashboard | 采集调用的延迟、token、成功率并可视化的监控面板 |
| 第 05 课 | MCP 智能工具集成平台 | 通过标准协议接入多个工具，让模型即插即用 |
| 第 06 课 | Multi-Agent 协作系统 | 多个分工不同的智能体协作完成复杂任务（含企业助手形态） |

## 怎么学

1. 先理解每个项目的"问题和架构"，再动手写代码，不要一上来就抄
2. 每个项目做完，主动加一个自己的功能——这是把项目变成真本事的关键
3. 养成写 README 的习惯：项目是干什么的、怎么装、怎么跑，讲给别人听
4. 遇到报错先自己排查（回看 11.4 AI 可观测性的思路），解决问题的过程就是成长
5. 负荷条款：每课核心代码控制在约 300 行内、保证本机能跑通，跑通后再选做扩展功能；不要照抄动辄几千行的"大而全"版本，那是学完本章后回头拆解的参考
