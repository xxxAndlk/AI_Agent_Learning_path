# LLM 工程基础 · 课程大纲

从这一章开始，你要真正动手，让大模型为你干活了。

前两章你学会了 Python，也搞懂了大模型背后的原理。这一章解决四个最基础、也最值钱的问题：怎么第一次把大模型调起来、怎么把话说清楚让它好好干活、怎么让它学会调用你给的工具、怎么让它老老实实按你规定的格式返回。后面所有的框架（LangChain、RAG、Agent）都是在这四件事上搭起来的，所以这一章请务必亲手敲代码，不要只看。

## 学习之前

- 已学完第 01 章 Python；第 02 章理论能帮你理解"它为什么这样"，但不强制
- 你需要：一台能上网的电脑、Python 3.10 以上、一个大模型平台的账号和一点 API 额度
- 第 01 课会手把手带你完成账号、Key、虚拟环境的全部准备，没接触过也不用担心

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | 动手调用你的第一个大模型 | 账号与 API Key、虚拟环境、装 SDK、发出第一次请求、读懂返回结果 |
| 第 02 课 | Prompt 工程：把话说清楚 | 好提示词的基本结构；给角色、给上下文、给示例、让它分步想；怎么一轮轮改 |
| 第 03 课 | Function Calling：让模型会用工具 | 模型并不直接执行代码，而是"决定调用哪个工具、给什么参数"；你执行后把结果喂回去 |
| 第 04 课 | 结构化输出：让它按格式回答 | 用 JSON 规范和校验，让模型返回程序能直接处理的数据，而不是一段自由文字 |

## 怎么学

1. 每段代码都亲手敲一遍、跑一遍，报错是正常的，学会看报错比一次成功更重要
2. API Key 当作银行卡密码保管，绝不写进要分享的代码，第 01 课会讲正确做法
3. 调用 API 会花一点点钱，课程示例都很小；先跑通再自己加花样
4. 第 02 课的提示词建议建个文档攒起来，这是你以后最常用的个人资产
