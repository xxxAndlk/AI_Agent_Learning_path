# 向量数据库（FAISS）· 课程大纲

RAG 要"翻资料"，就得在成千上万个向量里，快速找到和问题最接近的那几个。数据少时，挨个算一遍距离也无所谓；可一旦资料变成几十万、上百万条，每问一句都全量算一遍，慢到没法用。

向量数据库，就是专门解决"海量向量里快速找最近邻"这件事的工具。这一章我们从最经典、最轻量、几乎是行业标配入门款的 FAISS 学起：它是 Facebook（Meta）开源的一个库，装好就能用，非常适合先搞懂"向量索引"到底在干什么。这一章偏动手，我们会亲手建索引、查最近邻、调参数、存盘读取。

## 学习之前

- 已理解 Embedding 和"相似度"（第 02 章 / 第 05 章），知道向量是文字的"语义坐标"
- 会用 pip 装包即可；FAISS 的 CPU 版安装简单，不需要显卡，本机就能跑
- 本章我们用随机或手工生成的小向量练习，不必准备真实模型和 API Key

## 课次安排

| 课次 | 主题 | 你会搞懂的事 |
|------|------|--------------|
| 第 01 课 | 向量检索与第一个 FAISS 索引 | 暴力搜索为什么慢、什么是近似最近邻（ANN）；三种常见相似度；建一个 Flat 索引亲手查出最近邻 |
| 第 02 课 | FAISS 常用索引怎么选 | Flat / IVF / HNSW / PQ 各自的思路与取舍；速度、内存、准确率怎么换；关键参数怎么调（本课定位：FAISS 语境的索引调参实操，跨库通用原理在第 8 章展开） |
| 第 03 课 | 工程实践：增改、存盘与性能 | 向量增量添加、按 ID 管理、索引保存与加载、数据量大时的实用建议；GPU 与选型直觉 |

## 怎么学

1. 第 01 课先把"向量→索引→查询"这条最小链路跑通，再谈各种高级索引
2. 每种索引都动手改参数（如 nprobe、efSearch），观察"速度和准确率"的此消彼长——这种手感比记结论重要
3. 不必害怕英文术语，IVF、HNSW、PQ 背后都是很形象的思路，课程会先用直觉讲再给名字
4. FAISS 是库不是数据库服务，下一章我们会看带持久化、服务化的完整向量数据库，注意体会区别
